# 会后学习资源包

> 配套 PPT：[[ppt/outlines/国企AI宣讲-中高层完整版|国企中高层 AI 宣讲完整版]]

## 设计理念

PPT 最后一页只放 **1 个二维码**，指向一个移动端长页面。扫完往下滑，角色路径、课程、工具全在里面。

| 设计原则 | 说明 |
|:---|:---|
| **一个码** | 没有选择焦虑，扫就完了 |
| **按角色分流** | 班子/职能岗/技术岗各有最短路径，在页面内分区展示 |
| **从今天开始** | 每条路径的第一步都是"5 分钟内能完成"的事 |
| **落地页即全部** | 课程链接、工具速查、30天挑战入口都在同一个页面里 |

## 二维码指向

**唯一二维码** → 会后学习资源包 HTML（移动端优化长页面）

内容分区（自上而下滚动）：
1. 按角色 · 推荐路径（班子成员 4 周 / 职能岗 14 天 / 技术岗 4 周）

4. 30 天 AI 实战挑战入口

## 各分区内容

### 分区 1：按角色分流路径

**👔 班子成员路径（4周）**：
- 第1周：完成吴恩达《AI For Everyone》（6小时，Coursera免费旁听）
- 第2周：用豆包处理3件日常事务（邮件/报告/摘要）
- 第3周：让助理用 Kimi 整理一份50页行业报告
- 第4周：在部门会上分享你的AI体验

**🏢 本部职能岗路径（14天）**：
- 第1天：用豆包写一封邮件 → 第3天：Kimi读PDF → 第5天：通义听悟整理会议 → 第7天：AI写周报初稿
- 第14天：进入30天挑战系统学习

**💻 信息化条线路径（4周）**：
- 第1周：Elements of AI（中文版） → 第2周：Claude Code写脚本 → 第3周：Cursor搭看板 → 第4周：教一个同事

### 分区 2：工具速查卡

| 工具 | 定位 | 上手 |
|:---|:---|:---|
| 🫘 豆包 | 写邮件/报告/文案 | 打开 doubao.com → 输入需求 → 复制修改 |
| 🌙 Kimi | 读长文档/提取要点 | 打开 kimi.moonshot.cn → 上传PDF → 提取要点 |
| 🎙 通义听悟 | 会议录音→纪要 | 打开 tingwu.aliyun.com → 上传录音 → 生成纪要+待办 |
| 🤖 WorkBuddy | 无代码建系统 | 拖拽式搭建业务系统 |
| 🧠 Claude | 深度对话/分析 | 打开 claude.ai → 自然语言描述需求 |

### 分区 3：吴恩达 AI 通识课

- 链接：`https://www.coursera.org/learn/ai-for-everyone`
- 时长约6小时，零技术要求，免费旁听
- 全球企业管理者公认的AI通识标准

### 分区 4：30天AI实战挑战

- 每天15分钟，4周渐进
- 第1周初体验 → 第2周效率提升 → 第3周深度应用 → 第4周建立习惯
- 链接：`https://example.com/ai-30day`（替换为实际URL）

## 落地清单

- [ ] **部署 HTML**：将 `会后学习资源包.html` 部署到可访问的 URL（企业内网或公网）
- [ ] **生成二维码**：用目标 URL 生成二维码图片
- [ ] **替换 deck.html P39**：把二维码图片放入 P39 最后一页，替换占位 base64
- [ ] **打印测试**：确认手机可扫、页面正常显示
- [ ] **编写落地页实际内容**：将占位 URL 替换为真实链接（30天挑战、具体工具链接等）

## 使用方式

1. **PPT 最后一页**：展示 1 个二维码，演讲者说「扫这个码，从今天开始」
2. **会后群发**：把链接发到公司群，方便没到场的同事
3. **培训海报**：打印贴在办公区，持续一个月
