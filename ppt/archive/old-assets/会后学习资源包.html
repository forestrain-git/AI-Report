📋 模板 1：会议纪要整理

适用于通义听悟 / Kimi / 豆包

请将以下会议内容整理成结构化纪要，包含以下要素： 1. 决议事项：今天定了什么 2. 待办任务：具体要做什么 3. 责任人：谁负责 4. 时间节点：什么时候完成 5. 需要进一步讨论的问题：今天没定下来的 要求： - 用 bullet points，条理清晰 - 保留关键数据和金额 - 删除口头禅和重复内容 - 输出格式：先总结，再分条

📑 模板 2：政策文件/长报告快速解读

适用于 Kimi（支持上传 PDF）

请阅读这份文件，帮我提取以下内容： 1. 核心结论：用 3 句话概括 2. 关键数据：所有出现的数字、比例、金额 3. 与我相关：哪些内容需要我关注/行动 4. 疑问点：哪些地方说得不清楚 输出格式：先给核心结论，再分条展开。

今晚
  1. 打开 doubao.com，让它帮你写一封你一直在拖的邮件
  2. 打开 kimi.moonshot.cn，上传一份 50 页以内的 PDF，让它 10 分钟提取要点

⚠
三个避坑提醒（先看再动手）
  1. 不要把机密文件上传到公开 AI 工具——涉及商业秘密、人事、财务敏感数据的，先在内部脱敏
  2. AI 生成的内容一定要自己看一遍再发——它可能编数据、编人名、编政策条文。AI 是助手，你是负责人
  3. 不要一开始就追求"完美提示词"——用大白话说清楚需求就行，先用起来再优化

NEW 装一个自己的 AI 助手

在 Obsidian 笔记软件里装上 Claudian 插件，你就有了一个能读你的文件、帮你整理知识库、听你指挥的 AI 助手。全程约 30 分钟，不需要 IT 基础。

0
准备一个邮箱
1分钟

后面注册 DeepSeek 要用。QQ邮箱、163邮箱、Gmail 都行。

1
装 Obsidian
5 分钟
  1. 打开 obsidian.md，点黄色 Download
  2. 双击安装，一路下一步
  3. 打开后选"创建新库"，给笔记取个名字
2
申请 DeepSeek API Key
10 分钟
  1. 去 platform.deepseek.com，点 Sign Up 注册
  2. 登录后左侧找 API Keys，点 Create new key
  3. 复制那串 sk- 开头的密钥，立刻存好（发到微信文件传输助手）
  4. 左侧点 Top Up，充 10 块钱够用很久
💡 没有海外信用卡？淘宝搜"DeepSeek API充值"，找店家帮忙充。
3
装 Node.js
5 分钟
  1. 去 nodejs.org，点绿色 LTS 按钮下载
  2. 双击安装，一路 Next，最后 Install
  3. 重启电脑
4
装 Claude Code
3 分钟
  1. 按 Win 键，输入 cmd，右键"以管理员身份运行"
  2. 在黑窗口输入下面这行，按回车：
npm install -g @anthropic-ai/claude-code
  1. 等它跑完，输入 claude 回车，看到文字出来说明启动成功
  2. 输入 /exit 退出，关掉黑窗口
💡 为什么要做这一步：运行一次 claude 后，系统会自动创建 .claude 文件夹，下一步直接往里填配置。
5
创建配置文件
2 分钟
  1. 桌面右键 → 新建 → 文本文档 → 改名为 settings.json
  2. 粘贴以下内容：
{ "env": { "ANTHROPIC_AUTH_TOKEN": "你的apikey贴这里", "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic", "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-v4-flash[1M]", "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro[1M]", "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-v4-flash[1M]" } }
⚠️ 把 "你的apikey贴这里" 换成第 2 步申请的 sk- 开头的真实密钥
  1. 按 Win 键，输入 %USERPROFILE% 回车
  2. 找到 .claude 文件夹，把 settings.json 剪切进去覆盖
💡 .claude 是隐藏文件夹。如果看不到，在文件夹顶部点"查看" → 勾上"隐藏的项目"。
6
装 Claudian 插件
2 分钟
  1. 打开 Obsidian → 左下角齿轮（设置）
  2. 左侧找 "第三方插件" → 点"浏览"
  3. 搜索 Claudian → 安装 → 启用
7
配置 Claudian
2 分钟
  1. Obsidian 设置里找到 Claudian
  2. Settings Provider 选 Claude Code
  3. Permission Mode 选 Accept All Edits
  4. 语言（Locale） 选 中文
  5. 把 1M上下文窗口（Enable Sonnet 1M / Enable Opus 1M）打开
+
设置 Obsidian：监测所有类型文件
1 分钟
  1. Obsidian 设置 → "文件与链接"
  2. 把 "监测所有类型文件" 打开
8
开始用
  1. Obsidian 右侧应该能看到 Claudian 面板
  2. 底部输入框打字，按 Ctrl + Enter 发送
  3. 等几秒到一分钟，AI 回复就出来了
💡 如果没看到面板：按 Ctrl+P，输入 Claudian，选"Toggle chat view"。
💡
Claudian 怎么帮你建知识库

装好 Claudian 之后，试试这三句话：

  1. "按照 claude-kb.md 的要求，构建文件夹体系" —— Claudian 会自动创建 inbox/raw/wiki 等目录结构
  2. "处理 inbox" —— 把有价值的文件拖进 inbox 文件夹，说这句话，Claudian 自动分类、生成摘要、更新索引
  3. 直接聊天 —— 比如"帮我整理一份 AI 工具对比表""把这个报告的核心结论提炼出来"
