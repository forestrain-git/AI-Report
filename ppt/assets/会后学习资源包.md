## 设计理念

不发纸质材料（没人看），改用**二维码**——扫一个码就进入学习路径。

| 设计原则 | 说明 |
|:---|:---|
| **扫一个就够** | 5 个二维码覆盖所有角色，每个自成闭环 |
| **按角色分流** | 班子/职能岗/技术岗各有最短路径 |
| **从今天开始** | 每条路径的第一步都是"5分钟内能完成"的事 |
| **持续而非一次** | 社群码保证散会后不断线 |

## 五个二维码资源

### QR-1 📋 AI 快速入门指南（推荐首选）

**定位**：扫完立刻知道自己该做什么的"一页纸"。

**内容结构**（按角色分三个板块）：

**👔 班子成员路径（4周）**：
- 第1周：完成吴恩达《AI For Everyone》（6小时，Coursera免费旁听）
- 第2周：用豆包处理3件日常事务（邮件/报告/摘要）
- 第3周：让助理用 Kimi 整理一份50页行业报告
- 第4周：在部门会上分享你的AI体验

**🏢 本部职能岗路径（14天）**：
- 第1天：用豆包写一封邮件 → 第3天：Kimi读PDF → 第5天：通义听悟整理会议 → 第7天：AI写周报初稿
- 第14天：扫30天挑战码进入系统学习

**💻 信息化条线路径（4周）**：
- 第1周：Elements of AI（中文版） → 第2周：Claude Code写脚本 → 第3周：Cursor搭看板 → 第4周：教一个同事

**实现方式**：
- 首选：飞书文档（支持富文本、可更新、企业内直接访问）
- 备选：中建发展内部wiki页面
- 链接：`https://example.com/ai-quickstart`（替换为实际URL）

### QR-2 🎓 吴恩达 AI 通识课

**定位**：全球公认的AI入门第一课，管理层"统一语言"的最佳选择。

**直接链接**：`https://www.coursera.org/learn/ai-for-everyone`

| 属性 | 说明 |
|:---|:---|
| 讲师 | 吴恩达（Andrew Ng），Coursera创始人 |
| 时长 | 约6小时，4周课程（每周1-2小时） |
| 门槛 | 零技术要求，无代码无公式 |
| 费用 | 免费旁听（付费可获证书） |
| 评分 | 4.8/5，全球数百万学员 |
| 核心收获 | AI能做什么、不能做什么、企业如何拥抱AI、AI与社会 |

**为什么选这个**：
- 不是"中国式培训"——是全球企业管理者公认的AI通识标准
- 学完后，班子成员和中层能在同一频道上讨论AI

### QR-3 🔥 30天AI实战挑战

**定位**：把"我知道AI重要"变成"我每天都在用AI"。

**内容结构**（每天15分钟，4周渐进）：

| 周 | 主题 | 每日任务示例 |
|:---|:---|:---|
| **第1周** | 初体验 | 用豆包写邮件/Kimi读PDF/通义听悟整理录音 |
| **第2周** | 效率提升 | AI辅助PPT制作/数据整理/制度问答 |
| **第3周** | 深度应用 | AI分析行业报告/生成周报/辅助决策 |
| **第4周** | 建立习惯 | 形成个人AI工作流/分享经验/探索新工具 |

**实现方式**：
- 首选：飞书文档（每日推送一个任务卡片）
- 可选：企业微信群每日推送
- 链接：`https://example.com/ai-30day`（替换为实际URL）

### QR-4 🧰 工具速查卡

**定位**：扫完就能用的"工具急救包"。

**五个工具，每个附"3分钟上手"指南**：

| 工具 | 定位 | 上手步骤 |
|:---|:---|:---|
| 🫘 豆包 | 写邮件/报告/文案 | 打开 doubao.com → 输入"帮我写一封XX邮件" → 复制修改 |
| 🌙 Kimi | 读长文档/提取要点 | 打开 kimi.moonshot.cn → 上传PDF → 输入"提取这份报告的核心要点" |
| 🎙 通义听悟 | 会议录音→纪要 | 打开 tingwu.aliyun.com → 上传录音 → 自动生成纪要+待办 |
| 🤖 WorkBuddy | 无代码建系统 | 拖拽式搭建业务系统，适合非技术人员 |
| 🧠 Claude | 深度对话/分析 | 打开 claude.ai → 用自然语言描述需求 |

**实现方式**：
- 首选：飞书文档（可随时更新工具推荐）
- 链接：`https://example.com/ai-tools`（替换为实际URL）

## 落地清单

在 PPT 定稿前，需要完成以下工作：

- [ ] **确定QR-1内容**：编写"AI快速入门指南"飞书文档
- [ ] **确定QR-3内容**：编写"30天AI实战挑战"飞书文档（每日任务卡片）
- [ ] **确定QR-4内容**：编写"工具速查卡"飞书文档
- [ ] **确定QR-5社群**：创建企业微信群，生成群二维码
- [ ] **替换URL**：更新 `generate_qr_page.py` 中的URL，重新生成HTML
- [ ] **生成最终二维码**：运行脚本，导出HTML
- [ ] **嵌入PPT**：截图或导出为图片，放入PPT最后一页
- [ ] **打印测试**：确认二维码手机可扫

## 使用方式

1. **PPT最后一页**：展示5个二维码，演讲者说"扫一个码，从今天开始"
2. **会后飞书群**：把HTML链接发到公司群，方便没到场的同事
3. **培训海报**：打印贴在办公区，持续一个月
