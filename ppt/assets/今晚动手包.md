## 二、两个可直接复制粘贴的提示词模板

### 模板 1：会议纪要整理（适用于通义听悟 / Kimi / 豆包）

```
请将以下会议内容整理成结构化纪要，包含以下要素：

1. 决议事项：今天定了什么
2. 待办任务：具体要做什么
3. 责任人：谁负责
4. 时间节点：什么时候完成
5. 需要进一步讨论的问题：今天没定下来的

要求：
- 用 bullet points，条理清晰
- 保留关键数据和金额
- 删除口头禅和重复内容
- 输出格式：先总结，再分条
```

**怎么用**：
1. 通义听悟：上传录音 → 自动生成文字稿 → 把文字稿复制到 Kimi/豆包 → 粘贴上面提示词 → 得到纪要
2. 或者直接手机录音 → 转文字 → 丢给 AI

---

### 模板 2：政策文件 / 长报告快速解读（适用于 Kimi）

```
请阅读附件，完成以下分析：

1. 核心观点：文件最强调的三件事是什么
2. 关键数据：涉及金额、比例、时间节点、目标值
3. 与我司业务的关联点：哪些内容和中建发展的投资/环保/数字化/双碳业务相关
4. 行动建议：基于这份文件，我们可能需要关注或推进的事项
5. 风险点：文件中提到的限制、门槛、deadline

要求：用表格呈现，语言简洁，直接可用。
```

**怎么用**：
1. 打开 Kimi（kimi.moonshot.cn）
2. 点击"+"上传 PDF/Word 文件（支持一次性上传 50 个文件）
3. 粘贴上面提示词
4. 等 30 秒，直接出结果

**适合场景**：
- 100 页的环保政策文件，10 分钟提取要点
- 5 家投标人的技术标，一次性对比差异
- 季度经营分析报告，自动梳理关键数据

## 三、今晚就做：第一步行动清单

选一个你**这周最常做的活**，今晚试一次：

| 如果你的日常是...  | 今晚试这个                                    |
| ----------- | ---------------------------------------- |
| 开会、做纪要      | 打开通义听悟，上传最近一次会议录音，体验自动转写                 |
| 读文件、写分析     | 打开 Kimi，把一份 20 页以上的 PDF 丢进去，用模板 2        |
| 写材料、改稿子、答问卷 | 打开豆包，把你正在写的草稿发进去，说"帮我改得简洁正式，适合上报集团"      |
| 做 PPT       | 打开 Kimi，说"帮我根据以下内容生成 PPT 大纲"，然后把你的文字稿贴进去 |
| 整理数据 / 做表格  | 打开豆包，说"请把以下数据整理成表格，并计算同比环比"              |

**原则：别挑大事，越具体越好。**

**推荐从最简单的开始**：打开豆包，问它"帮我写一封关于 XXX 的邮件，语气正式，300 字以内"。

## 四、三个避坑提醒（先看再动手）

| 坑        | 表现                | 怎么避                          |
| -------- | ----------------- | ---------------------------- |
| **幻觉**   | AI 给出的数据/政策/法规是编的 | 关键数据必须人工核对原文，尤其是涉及金额、日期、法规条款 |
| **过度依赖** | 直接复制 AI 输出上交，不修改  | AI 输出是草稿，必须加上你的业务判断和公司语境     |
| **数据乱投** | 涉密文件上传到海外模型       | 见下方"安全提醒"，先分级再决定用哪个工具        |

---

## 五、安全提醒

| 数据级别 | 可用工具 | 原则 |
|---|---|---|
| 公开信息 / 行业资料 | 海外模型（ChatGPT/Claude）、国产模型均可 | 无限制 |
| 内部文档 / 项目资料 | 国产模型（Kimi、通义千问、豆包） | 数据不出境 |
| 涉密信息 | **不上任何云端 AI** | 本地处理 |

**核心原则：什么级别的数据，进什么级别的工具。**
