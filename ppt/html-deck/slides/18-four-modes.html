LLM 怎么干活？——四种工作模式
💬
Chat
你问我答，单次对话完成一个任务
自主度 ★★★★★
代表工具
ChatGPT、DeepSeek、Kimi、豆包
适用场景
写材料、查资料、头脑风暴、翻译、简单分析
已普及
✈️
Copilot
嵌入工作流，在你熟悉的工具里实时辅助
自主度 ★★★★★
代表工具
GitHub Copilot、Office Copilot、Cursor
适用场景
写代码补全、PPT 排版、Excel 公式、文档润色
大规模落地
🤖
Agent
给定目标，AI 自主规划步骤并执行
自主度 ★★★★★
代表工具
Claude Code、AutoGPT、Dify、Coze
适用场景
自动写代码并部署、自动抓取数据生成报告、智能客服
快速成熟
🌐
Multi-Agent
多个 AI 协作，各负责不同子任务
自主度 ★★★★★
代表工具
CrewAI、MetaGPT、多 Agent 编排框架
适用场景
复杂项目管理、多角色协同创作、供应链优化
已可用
维度 Chat Copilot Agent Multi-Agent
交互方式 对话窗口 嵌入工具 目标驱动 多角色协作
用户投入 高（需反复 prompt） 低（实时跟随） 中（设定目标即可） 中（设计协作流程）
适合谁 所有人 专业岗位 技术/业务骨干 技术团队
落地难度 极低 低 中 中高
