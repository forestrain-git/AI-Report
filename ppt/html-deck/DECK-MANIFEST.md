# 国企AI宣讲 HTML PPT —— 页面清单

共 **53 页**，1920x1080 宽屏，白色背景 + 品牌蓝色系。

## 使用方法

浏览器打开 `index.html`，支持：
- `→` / `←` 或空格键翻页
- `1-9` 数字键快速跳转
- `P` 键打印
- 自动缩放适应窗口
