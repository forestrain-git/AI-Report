# 中国建筑集团有限公司（CSCEC）

## 基本概况

中国建筑集团有限公司（China State Construction Engineering Corporation，简称CSCEC或中建集团）是全球最大的建筑投资建设集团，世界500强企业。

- **上市主体**：中国建筑股份有限公司（601668.SH）
- **核心业务**：房建、基建、地产、勘察设计、新业务
- **组织架构**：集团总部 + 多个工程局（一至八局）+ 专业公司 + 区域公司

## 2024-2026战略重点

### 1. 新质生产力培育

根据新华社2024年系列报道，中建集团围绕战略性新兴产业和未来产业布局：

| 维度 | 具体内容 |
|:---|:---|
| **核心策略** | 以科技创新赋能传统建造转型升级 |
| **技术方向** | 物联网、人工智能、BIM、数字孪生、模块化建筑 |
| **绿色低碳** | "光储直柔"建筑、近零能耗建筑、碳管理数据平台 |
| **代表性创新** | C-MiC混凝土模块化集成建筑、"零海拔屋"、X-MEN机器人、智能造楼机/造桥机 |

### 2. 业务梯队结构（以中建八局一公司2026届招聘为参考）

| 业务类型 | 具体领域 |
|:---|:---|
| **四大成熟业务** | 高端房建、基础设施、专业业务、投融资业务 |
| **四大成长业务** | 数字产业、城市更新、新能源、涉水业务 |
| **两大孵化业务** | 运营业务、绿色低碳 |

### 3. 创新业务孵化体系

- **中建发展**：集团层面的"新苗"业务培育平台
- **各工程局/二级单位**：结合自身优势探索差异化创新方向
- **专精特新企业**：中建钢构等获国家级"专精特新"认定
