# 中建发展（中国建筑发展有限公司）

## 基本定位

中建发展是中国建筑集团有限公司（中建集团）旗下的**创新业务孵化平台**，定位于集团"新苗"业务的培育主体，承担着为中建集团探索战略性新兴产业、推动产业转型升级的战略使命。

- **官方域名**：`cscdc.cscec.com`（China State Construction Development Company）
- **母公司**：中国建筑集团有限公司（CSCEC）
- **战略角色**：集团创新业务孵化器、新质生产力培育平台

## 核心业务布局（2024-2025）

中建发展提出了清晰的**三层业务架构**：

| 业务层级 | 具体领域 | 战略定位 |
|:---|:---|:---|
| **两大核心业务** | 生态环保、产业数字化 | 现有优势业务的巩固与扩大 |
| **探索关联领域** | 与建筑主业相关联的业务领域 | 业务边界的适度拓展 |
| **种子业务/战略性新兴产业** | 建筑行业前沿技术和颠覆性业务机会 | **抢位发展、错位发展** |

### 细分业务方向

1. **生态环保**
   - 水务运营：中建水务运营有限公司（2023年迁址苏州揭牌）
   - 固废处理、危废处理、水环境治理
   - "绿色建筑+综合能源+智慧运维"新模式

2. **产业数字化**
   - 数字产业投资与运营
   - 与建筑主业的数字化融合

3. **新能源**
   - 智能光伏项目
   - 储能、充电桩等配套设施
   - 综合能源服务

4. **城市运营**
   - 城市更新项目投资运营
   - 老旧小区改造
   - 智慧城市建设

## 与中建集团整体战略的关系

中建发展的定位与中建集团"十四五"后期至"十五五"的整体战略高度协同：

| 集团战略 | 中建发展的承接 |
|:---|:---|
| 新质生产力培育 | 作为集团创新业务孵化主体 |
| 战略性新兴产业占比提升 | 负责"新苗"业务的识别、培育、孵化 |
| 绿色低碳转型 | 生态环保、新能源为核心业务 |
| 数字化转型 | 产业数字化为两大核心业务之一 |
| 建筑工业化/智能建造 | 探索前沿技术和颠覆性业务机会 |

### 集团其他二级单位的参照

- **中建八局一公司**：将"运营业务、绿色低碳"列为**两大孵化业务**
- **中建西北院**：出台《创新业务发展专项规划》，2023年新兴业务新签合同额同比增长**325%**
- **中建数科**：探索"AI+建筑"数字化场景，逐步孵化产品
- **中建二局苏州项目**：首个百亿级城市更新项目，锚定"机器人+人工智能""高端智造及新一代信息技术"
