# 能碳平台

## 一句话定义

能碳平台是一款面向光伏及节能改造项目的**投资管理数字化系统**，核心能力是将项目文档中的非结构化数据（可研报告、合同、测算表）自动提取为结构化指标，支撑从项目立项到经济测算的全流程管理。

## 核心功能模块

| 模块 | 职责 | 关键能力 |
|------|------|---------|
| **光伏项目管理** | 维护项目基本信息 | 项目编号、名称、地点、面积、创建时间 |
| **资料库** | 项目文档集中管理 | 上传可研报告、测算表等文档，自动解析状态追踪 |
| **模块管理** | 项目子单元的生命周期管理 | 将项目拆分为屋顶光伏、照明节能、储能等模块，管理状态流转 |
| **指标审核** | 从文档中提取关键指标并人工确认 | AI 提取安装容量、首年发电量、上网电价等指标，标注来源页码与置信度，人工审核后入库 |
| **测算表版本** | 经济测算表的生成与版本管理 | 按模块生成 V1.0、V2.0 等测算表，支持下载回溯 |
| **指标库管理** | 统一指标标准维护 | 定义指标编码（如 `installed_capacity`）、名称、分类、数据类型、单位 |
| **模块类型配置** | 不同模块类型的指标模板配置 | 为屋顶光伏、照明节能、储能等类型绑定必填/选填指标清单 |

## 业务流程

### 模块生命周期

```
草稿 → 提取中 → 审核中 → 待业务测算 → 待财务测算 → 待生成输出 → 已完成
```

各阶段含义：
- **提取中**：系统从资料库文档中自动提取指标
- **审核中**：运营人员对提取指标进行人工确认或修正
- **待业务测算**：指标审核通过，等待业务端进行测算
- **待财务测算**：业务测算完成，等待财务端进行核算
- **待生成输出**：测算完成，等待生成正式测算表与文档
- **已完成**：全部输出物生成完毕

### 指标提取与审核流程

1. **配置期望指标**：在模块类型中预先定义该类型需要提取的指标清单（如屋顶光伏需提取安装容量、首年发电量、上网电价等）
2. **自动提取**：系统通过正则表达式 + LLM 从可研报告、合同中提取指标值，记录来源文档与页码
3. **置信度分级**：高 / 中 / 低，辅助审核人判断
4. **人工审核**：审核人可确认、修改或标记为不适用，必填指标全部确认后才能进入下一阶段
5. **指标入库**：审核通过的指标成为模块的正式数据，用于后续测算

## 设计特点

- **文档驱动**：以可研报告、合同等原始文档为数据源，减少手工录入
- **模块化拆解**：大型项目拆分为独立模块，各模块可并行推进、独立测算
- **指标标准化**：通过指标库统一数据口径，避免不同项目间指标定义混乱
- **流程阻断**：必填指标未审核完成时，系统阻断进入下一阶段，确保数据质量
