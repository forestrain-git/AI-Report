# AI Agent（智能体）

## 一句话定义

**AI Agent 是一个能"自己想、自己干"的 AI 系统。** 你给它一个目标，它会自动拆解任务、调用工具、处理中间结果，最终交付完整结果。

> **本质**：如果说大模型是"会思考的大脑"，Agent 就是"有大脑 + 有手脚 + 有工具 + 有记忆"的完整员工。

---

## 直观理解：从"百科全书"到"全能助手"

### 类比 1：天才实习生 vs 全能员工

| | 大模型（LLM） | AI Agent（智能体） |
|---|---|---|
| **比喻** | 博学但随性的天才实习生 | 能独立完成项目的全能员工 |
| **你告诉他** | "帮我写一份差旅报销说明" | "帮我把这个月的差旅报销整理了" |
| **他的反应** | 生成一段文字给你 | 打开邮箱 → 读取发票 → 核对标准 → 填写表单 → 发送审批 |
| **关键差异** | 只会"说" | 还能"做" |

### 类比 2：发动机 vs 自动驾驶汽车

| | 大模型（LLM） | AI Agent（智能体） |
|---|---|---|
| **比喻** | 强劲的法拉利发动机 | 一辆完整的自动驾驶汽车 |
| **特点** | 动力十足，但只会空转 | 有引擎 + 导航 + 车轮 + 传感器 |
| **结果** | 告诉你"可以怎么去" | 直接把你送到目的地 |

### 类比 3：美食评论家 vs 米其林主厨

| | 大模型（LLM） | AI Agent（智能体） |
|---|---|---|
| **比喻** | 美食评论家 | 米其林餐厅主厨 |
| **能力** | 知道所有菜谱，能描述味道 | 真正进厨房，洗菜、切配、炒菜、摆盘 |
| **产出** | 文本、建议、方案 | 可落地的实际结果 |

## Agent 能做什么？一个生活化的例子

**你说**："帮我规划下周去上海的出差"

| 阶段 | 普通大模型 | AI Agent |
|------|-----------|----------|
| 第一步 | 生成"去上海出差建议"文本 | 搜索北京→上海的高铁和机票 |
| 第二步 | — | 发现机票太贵，自动改搜高铁 |
| 第三步 | — | 根据公司差旅标准筛选酒店 |
| 第四步 | — | 把行程、预算、发票要求整理成表格 |
| 第五步 | — | 发送到你的邮箱并添加到日历 |

> Agent 的核心不是"回答更好"，而是"把事情办完"。

## Agent 的四大核心能力

```
        ┌─────────────┐
        │   你给目标    │
        └──────┬──────┘
               ↓
┌─────────────────────────────────────┐
│  1. 感知：读取邮件 / 查数据库 / 看网页  │
│  2. 规划：把大目标拆成可执行步骤      │
│  3. 行动：调用工具、操作软件、发请求   │
│  4. 记忆：记住偏好、经验、中间结果     │
└─────────────────────────────────────┘
               ↓
        ┌─────────────┐
        │   交付结果    │
        └─────────────┘
```

| 能力 | 通俗解释 | 类比 |
|------|---------|------|
| **感知** | 能获取外部信息 | 眼睛和耳朵 |
| **规划** | 会拆分任务、排序执行 | 项目经理的 To-Do 清单 |
| **工具调用** | 能使用各种软件和 API | 手脚和工具箱 |
| **记忆** | 记住你说过的和用户反馈 | 笔记本和经验库 |

---

## 公式：Agent = 大模型 + 推理 + 工具 + 记忆

```
Agent（智能体）= 大模型（大脑）+ 推理引擎（规划/逻辑）+ 工具（手脚）+ 记忆（经验）
```

| 组件 | 作用 | 类比 |
|------|------|------|
| **大模型 LLM** | 提供知识和推理能力 | 大脑 |
| **推理引擎** | 拆解任务、规划步骤、反思修正 | 导航仪 / SOP |
| **工具 Tools** | 连接外部世界，执行实际操作 | 手脚 |
| **记忆 Memory** | 保存历史、偏好、中间结果 | 经验库 |

> 所以：**大模型是 Agent 的"大脑"，Agent 是大模型的"身体"和"行动力"。**

---

## Agent vs 大模型：核心区别

| 维度 | 大模型（LLM） | AI Agent（智能体） |
|---|---|---|
| **核心功能** | 认知与生成 | 规划与执行 |
| **工作模式** | 被动响应 | 主动行动 |
| **输入** | 文本提示 | 高级目标（如"规划北京三日游"） |
| **输出** | 文本、代码、想法 | 动作、结果、完成的交付物 |
| **自主性** | 无，需人类一步步驱动 | 高，能自主决策、调整策略 |
| **工具使用** | 只能生成建议，不直接操作 | 可调用 API、数据库、浏览器等 |
| **失败处理** | 返回错误文本 | 自动重试、换备用策略 |
| **典型场景** | 聊天、写作、翻译、问答 | 复杂任务自动化 |

## 央企案例：南方电网"大瓦特"智能体

南方电网的"大瓦特"是**电力行业首个全自主可控的人工智能大模型**，2025 年已演进为完整的智能体体系：

### 场景 1：变电站倒闸操作机器人
- 接收指令后**一键分解任务**
- 自动调用开关柜接口
- 完成"运行→热备用"全流程倒闸操作
- 实现"对话直达安全执行"

### 场景 2：95598 智能客服
- "五位一体"智能客服体系
- 高频咨询查询**机器代人率超 90%**

### 场景 3："元焏"营销稽查智能体
- 基于"大瓦特"+ DeepSeek
- 营销稽查从"人工抽检"迈入"AI 稽查"

> 这些不是"更聪明的聊天机器人"，而是**能看懂图纸、会操作设备、能闭环执行**的智能体。

## Agent 的典型应用形态

| 类型 | 例子 | 适合解决的场景 |
|------|------|---------------|
| **个人助理型** | Manus、Claude Code | 订票、整理资料、写代码 |
| **业务助手型** | 南方电网"大瓦特" | 设备巡检、客服、营销稽查 |
| **知识管理型** | 企业制度问答 Agent | 查制度、写公文、辅助决策 |
| **数据分析型** | 财报分析 Agent | 自动抓取数据、生成图表、撰写分析 |
| **流程自动化型** | RPA + Agent | 跨系统自动操作、审批流转 |

## 常见误区

| 误区 | 真相 |
|------|------|
| "Agent 就是更厉害的大模型" | 不是。Agent 是在大模型基础上加了规划、工具、记忆等模块的完整系统 |
| "Agent 可以无人监督" | 还不能。复杂决策和关键动作仍需人类确认 |
| "Agent 能替代所有岗位" | 目前是"替代重复环节"+"增强人"，不是替代人 |
| "建 Agent 必须会编程" | 低代码平台已出现，但复杂场景仍需技术团队支持 |
