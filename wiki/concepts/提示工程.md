# 提示工程（Prompt Engineering）

## 一句话定义

提示工程是**设计和优化你给 AI 的指令**，让 AI 更准确地理解你的意图，从而输出更高质量的结果。简单说，就是"学会跟 AI 说话"。

## 直观理解：把 AI 当成一个聪明但需要明确指示的实习生

| 场景 | 不好的提示 | 好的提示 | 效果差异 |
|------|-----------|---------|---------|
| 写周报 | "帮我写周报" | "帮我写一份市场部周报，本周完成了3场线下活动，新增客户50人，下周计划拜访10家大客户，要求用数据说话，语气正式" | 后者直接可用 |
| 分析数据 | "分析一下" | "分析这份销售数据，找出增长最快的前3个产品，并用柱状图描述的形式呈现" | 后者结构清晰 |
| 学习概念 | "解释一下区块链" | "用'快递驿站'做类比，向一个完全不懂技术的初中生解释区块链，不超过200字" | 后者通俗易懂 |

## 通用提示公式：RTFC 框架

```
┌─────────────────────────────────────────────┐
│  R - Role（角色）                              │
│     你是谁？例如："你是一位资深财务分析师"        │
├─────────────────────────────────────────────┤
│  T - Task（任务）                              │
│     要做什么？例如："请分析这份报表"              │
├─────────────────────────────────────────────┤
│  F - Format（格式）                            │
│     输出形式？例如："用表格呈现，包含3列"         │
├─────────────────────────────────────────────┤
│  C - Constraints（约束）                       │
│     限制条件？例如："不超过500字，用中文"         │
└─────────────────────────────────────────────┘
```

### 完整示例

```
【角色】你是一位有10年经验的建筑行业项目管理专家
【任务】帮我写一份关于智慧工地建设的项目建议书大纲
【格式】按"背景-目标-实施方案-预期效果-预算概览"五部分组织
【约束】语言正式、适合向国企领导汇报，每部分不超过5个要点
```

## 六大核心技巧

### 1. 角色扮演法

给 AI 设定一个专业角色，输出质量立刻提升。

```
❌ "帮我修改这段文字"
✅ "你是一位资深公文写作专家，请修改以下文字，使其更符合国企公文规范，
    要求用词严谨、逻辑清晰、格式规范："
```

### 2. 提供上下文（Context）

AI 不知道你所在的公司、行业、背景，你需要主动告诉它。

```
❌ "写一份培训方案"
✅ "我是中建发展总部人力资源部员工，公司约500人，
    需要为总部员工做AI入门培训，听众多为35-50岁非技术岗位人员，
    请写一份2小时的培训方案"
```

### 3. 示例引导（Few-Shot）

给 AI 一个例子，它就能"照猫画虎"。

```
请按以下格式总结会议纪要：

示例：
会议主题：Q3季度销售复盘
参会人员：张总、李经理、王主管
核心决议：
1. 下季度目标上调20%
2. 新增华东区域市场投入
待办事项：
- 李经理：制定详细方案（截止10月15日）

现在请按同样格式总结以下内容：
[粘贴会议内容]
```

### 4. 思维链（Chain-of-Thought, CoT）

让 AI "一步一步想"，适合复杂问题。

```
❌ "计算：一个项目A投资100万，年化收益8%；项目B投资80万，年化收益12%。
    3年后哪个项目总收益更高？"

✅ "请一步一步计算：
    第一步：计算项目A 3年的总收益
    第二步：计算项目B 3年的总收益
    第三步：比较两者并得出结论"
```

### 5. 指定输出格式

```
"请用以下JSON格式输出："
"请用表格形式呈现，包含三列："
"请用Markdown格式输出："
"请用 bullet points 列出5条："
```

### 6. 分步骤拆解复杂任务

把大任务拆成小步骤，逐次交互。

```
第一步："请帮我头脑风暴，列出10个AI在建筑工程领域的应用场景"
第二步："从以上10个场景中，选出最适合我们中建发展的5个，并说明理由"
第三步："为第2个场景写一份简要实施方案"
```

## 常见错误与修正

| 错误类型 | 错误示例 | 修正方法 |
|---------|---------|---------|
| 太模糊 | "帮我写点东西" | 明确主题、用途、受众、字数 |
| 太简短 | "分析" | 说明分析什么、用什么方法、输出什么 |
| 一次提太多要求 | "帮我写一篇论文、做PPT、还要翻译成英文" | 拆成多个步骤，一次一个任务 |
| 不验证结果 | 直接复制 AI 输出 | 关键数据、事实必须人工核对 |
| 不迭代 | 一次不满意就放弃 | 告诉 AI "这里不对，请修改..." |

## 提示词进阶：系统化提示词模板

### 会议纪要整理

```
你是一位专业的会议记录整理专家。请将以下会议录音转录稿整理成结构化纪要。

要求：
1. 提取会议主题、时间、参会人员
2. 分条列出核心决议（每条用"决议："开头）
3. 提取待办事项，标注责任人和截止时间
4. 去除口语化表达和重复内容
5. 用正式的商务语言

会议内容：
[粘贴内容]
```

### 公文/报告撰写

```
角色：你是一位国企公文写作专家，熟悉建筑行业术语。
任务：撰写[报告/通知/请示]
背景：
- 公司：中建发展总部
- 受众：集团领导
- 用途：汇报[具体事项]
要求：
- 结构完整（标题-正文-结尾）
- 语言严谨正式
- 突出数据和成效
- 篇幅约[XXX]字
```

### 数据分析辅助

```
你是一位数据分析师。请分析以下数据并给出洞察。

数据：
[粘贴数据]

要求：
1. 计算关键指标（同比、环比、增长率等）
2. 指出3个最重要的发现
3. 用一句话总结核心结论
4. 建议2-3个后续行动
```

## 针对 Claude Code 的提示技巧

Claude Code 作为编程助手，有一些特殊技巧：

1. **用 `@` 引用文件**：`@src/report.docx 请分析这份报告`
2. **用 `!` 执行命令**：`!ls` 直接执行 shell 命令
3. **计划模式**：复杂任务先用 `/plan` 制定计划，再执行
4. **精确描述需求**：说明技术栈、约束条件、预期行为

## PPT 表达建议

- **适合用图**：RTFC 框架图、"差提示 vs 好提示"对比卡片
- **适合互动**：现场让听众写一个提示词，然后一起优化它
- **适合练习**：准备一个真实工作场景（如写周报），让听众现场写提示词
