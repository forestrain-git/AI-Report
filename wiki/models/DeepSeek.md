# DeepSeek 系列模型

## 模型概览

DeepSeek 是由中国公司**深度求索**（杭州幻方量化旗下）开发的大语言模型系列。2025 年初，DeepSeek-R1 以**极低的训练成本**实现了接近 OpenAI o1 的推理能力，震惊全球 AI 圈，被称为"AI 界的拼多多"。

## 版本演进

| 版本 | 发布时间 | 核心特点 |
|------|---------|---------|
| DeepSeek-V2 | 2024年5月 | MoE 架构，性价比突出 |
| DeepSeek-V3 | 2024年12月 | 6710亿参数，性能比肩 GPT-4o，训练成本仅557万美元 |
| DeepSeek-R1 | 2025年1月 | 推理模型，强化学习驱动，数学和编程能力顶尖 |
| DeepSeek-V4 | 2025年 | 持续迭代，多模态能力增强 |

## 核心技术：MoE（混合专家模型）

DeepSeek 采用 **MoE（Mixture of Experts）** 架构：

```
传统模型：6710亿参数 → 每次推理都要激活全部参数 → 计算量巨大
MoE 模型：6710亿参数 → 每次推理只激活约370亿参数 → 计算量大幅降低

比喻：
- 传统模型 = 每次看病都要全院会诊
- MoE 模型 = 根据病情自动匹配最相关的 3-5 个专家
```

这就是 DeepSeek 能以**1/10 的成本**达到顶尖性能的秘密。

## 两大主力模型

### DeepSeek-V3（通用模型）

- **定位**：日常对话、写作、翻译、知识问答
- **特点**：速度快、成本低、中文表达自然
- **适用**：大多数日常任务

### DeepSeek-R1（推理模型）

- **定位**：复杂推理、数学、编程、逻辑分析
- **特点**：会"一步步想"，展示推理过程
- **适用**：需要深度思考的问题

```
问 DeepSeek-V3："357 × 482 = ?"
→ 直接给出答案（可能算错）

问 DeepSeek-R1："357 × 482 = ?"
→ 展示思考过程：
  "让我逐步计算：
   357 × 400 = 142800
   357 × 80 = 28560
   357 × 2 = 714
   142800 + 28560 = 171360
   171360 + 714 = 172074"
→ 给出答案：172074（正确）
```

## 使用方式

### 1. 官方网页/APP
- 访问 chat.deepseek.com
- 国内直接可用，无需翻墙
- 免费使用（有一定额度限制）

### 2. API 接入
- 价格极低：V3 约 2 元/百万 Token，R1 约 4 元/百万 Token
- 支持第三方平台和工具接入

### 3. 本地部署（Ollama）
```bash
# 安装 Ollama 后
ollama run deepseek-r1:14b    # 14B 参数版（普通电脑可跑）
ollama run deepseek-r1:32b    # 32B 参数版（需较好显卡）
```

### 4. 第三方平台
- 硅基流动（SiliconFlow）
- 火山引擎
- 阿里云百炼
- 腾讯云 TI 平台

## 局限性与注意事项

- **审查机制**：部分敏感话题会被拒绝回答
- **知识截止日期**：训练数据有截止日期
- **创意写作**：在文学性、情感表达上略逊于 Claude
- **多模态**：图像理解能力仍在发展中

## 对中建发展员工的意义

1. **零门槛使用**：不用翻墙，手机/电脑直接访问
2. **免费额度充足**：日常办公完全够用
3. **中文场景友好**：写公文、整理会议纪要、翻译都表现优秀
4. **本地部署可选**：如涉及敏感数据，可部署在企业内网
