# Claude 系列模型

## 模型概览

Claude 是由 **Anthropic** 公司开发的大语言模型系列，以**安全性、长上下文处理能力和编程能力**著称。Anthropic 由 OpenAI 前研究副总裁 Dario Amodei 等人于 2021 年创立，核心理念是"AI 安全对齐"。

## 版本演进

| 版本 | 发布时间 | 核心特点 |
|------|---------|---------|
| Claude 1/2 | 2023年 | 初代产品，对话流畅，安全过滤严格 |
| Claude 3 系列 | 2024年3月 | 引入"Artifacts"实时预览，多模态（识图），三档模型（Opus/Sonnet/Haiku） |
| Claude 3.5 Sonnet | 2024年6月 | 编程能力大幅提升，一度成为开发者首选 |
| Claude 3.7 Sonnet | 2025年2月 | 扩展思考模式（Extended Thinking），推理能力增强 |
| Claude 4 系列 | 2025年 | Opus 4.6 / Sonnet 4.6，Claude Code 的核心引擎 |

## 核心优势

### 1. 长上下文窗口

Claude 支持 **200K Token**（约 15 万字）的上下文，这意味着你可以：
- 一次性上传一整本书让 AI 分析
- 上传几十页合同让 AI 审查
- 进行超长对话而不会"遗忘"前面的内容

### 2. 编程能力

Claude 在代码生成、代码审查、bug 修复方面表现优异，是 Claude Code（AI 编程助手）的核心引擎。

### 3. AI 安全与对齐

Anthropic 强调"Constitutional AI"（宪法 AI），通过规则约束让模型：
- 拒绝生成有害内容
- 承认不确定性（"我不知道"而非瞎编）
- 减少幻觉（胡说八道）

### 4. Artifacts 功能

在网页版对话中，Claude 可以生成独立的内容块（代码、文档、图表），用户可以直接在侧边栏编辑和预览。

## 使用方式

### 网页版（Claude.ai）
- 免费版：Claude Sonnet，有限次数
- Pro 版（$20/月）：Claude Opus + 更高使用额度
- Team 版：团队协作功能

### Claude Code（终端工具）
- 命令行 AI 编程助手
- 直接操作本地代码库和文件
- 详见 [[wiki/tools/Claude-Code|Claude Code 工具页]]

### API 接入
- 开发者可通过 Anthropic API 将 Claude 集成到自己的应用中
- 支持流式输出、系统提示词、工具调用等高级功能

## 局限性与注意事项

- **知识截止日期**：训练数据有截止日期，不能回答最新事件
- **计算能力弱**：复杂数学计算可能出错
- **国内访问**：官网需要特殊网络环境，可通过 API 中转或企业方案使用
- **幻觉问题**：虽然相对较少，但关键信息仍需人工核实
