# 中建发展AI硬件战略 · 决策提案

> 本文件面向发展主要领导，目标：**30分钟内做出三个决策**。
> 支撑细节见各方向独立分析文件（22份五步法+评分汇总+全景分析）。

## 一、全景结论：三条腿走路

穷举全球165款AI硬件 → 排除115款不相关的 → 对剩余36款+建筑机器人做七维评分和五步法深度分析 → 形成**三条腿**的战略框架。

```
┌──────────────────────────────────────────────────────────────┐
│  腿一：集成+升级（在现有硬件上叠加AI层）                          │
│  · AI安全帽：中建电商已有最低成本定位安全帽+现成团队，叠加AI能力层   │
│  · 录音/翻译：零成本采购，对接制度审核/投标评审                    │
│  · 边缘推理/企业AR：技术底座，依附推进                            │
│  本质：不造硬件，在现有硬件上加AI                                 │
├──────────────────────────────────────────────────────────────┤
│  腿二：创造（用独占数据造市场没有的专用AI硬件）                     │
│  · 档案专用智能扫描仪（管理学院已有合同）                          │
│  · 工地AI摄像头·自训版（4100工地监控影像）                        │
│  · 管网检测AI盒子（博铭维合作+十五五77万公里管网改造）             │
│  · 建材质量AI检测仪（云筑网交易质检数据）                         │
│  本质：用数据壁垒，造市场上做不出的产品                           │
├──────────────────────────────────────────────────────────────┤
│  腿三：投资（建AI硬件投资平台，用资本获取做不了的能力）              │
│  · 建筑AI机器人：已接触方石/自筑/自砌/奥卡/大方/中杰等创始人        │
│  · 工业AI无人机/智能建造装备/AI传感终端：待筛选                    │
│  · 原则：只投AI硬件，不投纯机械；只参股，不控股                    │
│  本质：不造硬件，用资本锁定最有价值的AI硬件公司                    │
└──────────────────────────────────────────────────────────────┘

三条腿共享同一个底层逻辑：
壁垒不在硬件本身，在中建发展独占的场景和数据。
```

## 三、关键风险与对策

| 风险 | 严重程度 | 对策 |
|:---|:---:|:---|
| **中建电商做安全帽的成本最低定位 vs AI安全帽的SaaS定位** | 中 | 不竞争——中建电商管硬件+渠道，AI能力层（SOS/跌倒/SaaS/数据平台）叠加在现有产品上 |
| **建筑机器人创始人只接受参股不接受控股** | 已解决 | L1少数股权投资（5-15%）为唯一可行路径，L3控股封存 |
| **腿二小模型封装的产品市场验证不足** | 中 | 每个产品先用2-4周做离线模型验证，成本<1万元/个 |
| **团队缺M&A能力和硬件供应链经验** | 高 | 腿三需引进1-2名产业投资背景人才；腿一依托中建电商现有团队 |
| **央企管控 vs 创业公司灵活性的投后整合冲突** | 高 | 只做少数股权（5-15%），不控股，减少管控摩擦 |

## 四、三个决策请求

### 决策1：三条腿的总体定位是否认可？

> 三条腿并行推进，但资源投入有优先级：
> - 腿一（AI安全帽）是**今年的核心战役**——中建电商现有团队+AI能力层叠加，最快出成果
> - 腿二（小模型封装）是**技术验证年**——每个产品先做离线模型验证，成本低、风险小
> - 腿三（投资平台）是**能力建设年**——第一笔L1少数股权投资（3000-5000万），用12个月跑通模式

**请确认：三条腿并行的总体方向是否认可？**

### 决策2：AI安全帽由中建电商现有团队承接，是否同意？

> 中建电商已在做成本最低的定位安全帽，有现成团队和供应链。AI安全帽不是"启动新项目"，而是在现有产品上叠加AI能力层（SOS/跌倒检测/SaaS平台/数据回流）。执行主体=中建电商现有团队+AI研发能力支撑。

**请确认：AI安全帽由中建电商现有团队承接是否可行？**

### 决策3：AI硬件投资平台是否启动？

> 建筑AI机器人赛道已接触方石/自筑/自砌/奥卡/大方/中杰等创始人，反馈积极（欢迎参股/不同意控股）。建议：
> - 第一笔投资3000-5000万（L1少数股权，5-15%）
> - 需要引进1-2名有产业投资经验的人才
> - 原则：只投AI硬件，不投纯机械；只参股，不控股

**请确认：是否启动AI硬件投资平台，第一笔投资预算3000-5000万？**
