# 中建发展AI硬件方向 · 七维评分汇总

> 基于 [[七维评分体系]] 统一评估。评分逻辑：先看行业值不值 → 再看自己行不行 → 最后扣风险。
> 总分 = ①+②+③+④+⑤+⑥-⑦，满分100。

## 判定标准

| 总分 | 判定 |
|:---:|:---|
| **75-100** | ✅ 建议推进 |
| **50-74** | ⚠️ 谨慎推进 |
| **25-49** | ⚠️ 需重大调整 |
| **<25** | 🔴 不建议 |

## 硬件适配说明

七维体系是通用创业评估框架，非软件专用。唯一微调：⑤商业模型中毛利率标准，硬件天然低于纯软件——≥35%即可入高分档（原软件标准为≥40%）。

| | 软件方向(22单元) | 硬件方向(21单元) |

| **⚠️ 谨慎推进** | 10个 | 10个(50-74分段) |
| **⚠️ 需调整** | 3个 | 6个(25-49分段) |
| **🔴 不建议** | 2个(TD-01/TD-02) | 2个(HW-01/HW-20) |

**核心差异**：软件方向Top5集中在82-89分；硬件方向Top3在80-84分，低了约5分。差距不在需求或方案，在**商业模型**——硬件天然比软件毛利低、天花板受限、运营复杂度更高。

## 三个高分方向的共同特征

| 特征 | HW-03(84) | HW-17(81) | HW-16(80) |
|:---|:---|:---|:---|
| 行业预判 | 6/6全过 | 6/6全过 | 6/6全过 |
| 需求刚性 | 政策+安全强制 | 双碳+600亿m2 | 泵坏停机=直接损失 |
| 数据壁垒 | 1400万工人 | 建筑缺陷热力图 | 泵站故障标签 |
| 硬件策略 | 集成现有 | AI自研+硬件OEM | AI自研+硬件OEM |
| LTV/CAC | 15.1 | 12.3 | 53 |

**共同模式**：三个高分方向都不是"卖硬件赚钱"，而是——硬件是入口，数据是壁垒，软件/SaaS是利润来源。
