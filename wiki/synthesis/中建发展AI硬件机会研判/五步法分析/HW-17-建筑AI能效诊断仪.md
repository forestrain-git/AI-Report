## 二、行业预判（六模块）

### M1 拆解行业

**产业链图**

```
上游（传感器/芯片）        中游（硬件整机）         下游（应用/服务）        终端用户
红外探测器(氧化钒/非晶硅) → 手持热像仪整机      → 建筑能效检测服务    → 建筑业主/物业公司
AI推理芯片(边缘NPU)      → AI算法嵌入端侧      → 能效诊断报告输出    → 节能改造公司
可见光摄像头模组         → 双光融合设备          → 改造建议+节能预估   → 住建部门/检测机构
                        → 能碳平台数据采集前端   → 碳交易核算支撑     → 碳交易市场
```

**利润分配**（从终端服务费100元拆解）

| 环节 | 毛利率 | 说明 |
|:---|:---:|:---|
| 红外探测器+传感器 | 20-30% | Flir自研探测器毛利高，国产低成本替代空间大 |
| 手持热像仪整机制造 | 20-35% | 硬件成熟，海康/Hikmicro毛利率35%+，竞争充分 |
| **AI算法+缺陷识别引擎** | **60-80%** | 软件层，边际成本极低，核心壁垒所在 |
| **能效诊断报告+改造方案** | **50-70%** | 数据积累越多，诊断越精准，规模效应强 |
| 检测服务（上门巡检） | 30-45% | 人工密集型，但AI可大幅压缩人力成本 |

**关键控制节点**：
- **数据壁垒型**：建筑缺陷标注数据（热力图+可见光配对标注）是核心稀缺资源
- **技术壁垒型**：AI缺陷自动分类模型（冷热桥/保温缺陷/门窗漏气/幕墙渗水）的精度决定了产品竞争力
- **渠道控制型**：能碳平台已有客户关系和对接接口，是天然分发渠道

**可优化环节**：当前市场上建筑能效诊断主要靠人工——检测师手持热像仪走一圈，拍照后回办公室人工判读。一个中型建筑（5000平方米）从检测到出报告需3-5天。AI介入后可将"检测-识别-报告"压缩到2-4小时，效率提升10倍以上。

### M2 洞察变化

| 维度 | 变化 | 量级 | 证据 |
|:---|:---|:---:|:---|
| **政策法规** | 国标要求2025年城镇新建建筑100%绿色，既有建筑改造强制推进 | 🔴大 | 住建部"先体检后更新"原则，到2030年完成3.5亿m²改造 |
| **政策法规** | EU CBAM碳关税+国内碳市场扩容至建筑行业 | 🔴大 | 出口型建筑企业面临碳关税，需准确的能效/碳排数据 |
| **新技术** | 边缘AI芯片成熟（Jetson Nano/树莓派AI Kit），端侧推理成本趋零 | 🟡中 | 7B参数以下模型可在端侧运行，无需云端 |
| **新技术** | 轻量级视觉大模型（ViT/MobileSAM）精度达95%+，可在嵌入式设备部署 | 🔴大 | 10亿参数级视觉模型在缺陷分类上已超越人工经验 |
| **需求侧** | 全国既有建筑超600亿m²，90%以上非节能建筑 | 🔴大 | 建筑能耗占社会总能耗30%+，节能改造从可选变强制 |
| **需求侧** | 老旧小区改造从"刷墙加电梯"延伸到"系统性节能改造" | 🔴大 | 中央财政通过专项债/超长期国债提供资金 |
| **供给侧** | 热成像硬件成熟（Flir/海康/大疆/睿创微纳），价格持续下降 | 🟡中 | 手持热像仪从5-10万降到1-3万，手机插件式仅2000-5000元 |
| **供给侧** | 全球有AI+无人机热成像初创（Lamarr.AI/飞行者科技），但中国**手持+端侧AI**市场空白 | 🟡中 | 无人机适合高空/大面，手持适合精细巡查——两者互补 |

**判断**：这是一个**四维共振的系统性变化**。政策（双碳刚性约束 + 绿色建筑强制）+ 技术（边缘AI成熟 + 视觉大模型精度达标）+ 需求（600亿m²既有建筑 + 90%非节能）+ 供给（热成像硬件降价至消费级）同时发力。变化量级足以支撑百亿级公司。

**时间机器验证**：美国Lamarr.AI（MIT/Georgia Tech背景）2024年已获110万美元融资，服务医疗/教育/市政建筑，已验证"AI+热成像=建筑能效诊断"的商业模式可行。中国市场更大（600亿m² vs 美国约320亿m²），但供给端空白更明显。

### M3 预判稳态B

**原子级需求拆解**

| 用户 | 场景 | 解决什么问题 | 愿付多少钱 |
|:---|:---|:---|:---|
| 物业公司/建筑业主 | 外墙巡检（手持走一圈） | 不知道哪里漏能、保温层是否完好、门窗是否漏气 | 5000-20000元/次 |
| 节能改造公司 | 改造前诊断+改造后验证 | 没有定量数据支撑改造方案设计，无法证明改造效果 | 8000-15000元/项目 |
| 住建部门/检测机构 | 老旧小区批量体检 | 人工检测效率低（3-5天/栋），无法规模化 | 3000-8000元/栋（批量） |
| 能碳平台运营方 | 能效数据采集前端 | 只有电表/能耗看板，不知道"哪里耗能、怎么改" | 设备采购+年费订阅 |
| 碳交易/绿色金融机构 | 节能效果第三方验证 | 缺乏可信的改造前后对比数据，绿色信贷无依据 | 按项目分成或年费 |

**稳态B推演**：

> （双碳政策强制 + 600亿m²既有建筑改造需求）→（使得建筑能效从"被动看能耗数据"转向"主动诊断+定位缺陷"）→（叠加边缘AI模型精度达到实用水平 + 热成像硬件降价）→ **建筑能效诊断从"人工经验判读"转向"AI自动化诊断"，出现手持设备+AI一体化的专用硬件品类。头部玩家凭借缺陷标注数据飞轮（检测越多→数据越多→模型越准→产品越好）形成寡头格局。**

**HW-17在稳态B中的位置**：**建筑能效AI诊断的"第一台专用设备"**——不同于通用热像仪（Flir/海康，靠人工判读）+ 不同于无人机方案（Lamarr.AI/飞行者科技，适合高空大面），HW-17定位为"手持+边缘AI"的人机协同诊断工具，覆盖从外墙到门窗到幕墙的全场景精细诊断，对接能碳平台形成"诊断→方案→改造→验证→碳交易"闭环。

### M4 Timing

**周期定位**：**早期探索 → 爆发增长的临界点**

- 热成像硬件已成熟（全球手持热像仪市场2026年约18.3亿美元），价格降至消费级
- 边缘AI芯片成熟（Jetson/树莓派AI Kit），端侧推理成本趋零
- AI缺陷检测模型精度达标（视觉大模型在建筑缺陷分类上达到实用水平）
- 中国市场尚无"手持热成像+建筑AI能效诊断"一体化产品——窗口期正好

**窗口期判断**：窗口已开，先发优势期约 **12-18个月**。原因：
- AI热成像建筑检测的全球初创（Lamarr.AI/飞行者科技）主攻无人机路线，手持+端侧AI是差异化空白
- 中国既有建筑改造政策2026-2027年集中落地，需求爆发在即
- 海康/大疆/睿创微纳有硬件能力但缺乏建筑缺陷AI标注数据，12-18个月可以建立数据壁垒

**太早风险**：低 — 硬件和AI技术均已成熟，不存在等技术的风险。需求端政策已明确，不是"可能发生"而是"正在发生"。
**太晚风险**：中高 — 海康/Hikmicro已在热像仪中嵌入基础AI功能（测温分析），若他们拿到足够的建筑缺陷标注数据并自研专用模型，12-18个月可能推出类似产品。

## 三、五步法逐层分析

### Step 1 需求

**目标用户**：
1. **物业公司/建筑业主**（核心）：管理多栋建筑的物业公司，需要定期巡检建筑外墙、门窗、幕墙的能效状况
2. **节能改造公司**（高价值）：改造前需定量诊断、改造后需效果验证，是付费意愿最强的客户
3. **住建部门/检测机构**（规模化）：老旧小区批量体检，政府购买服务模式
4. **能碳平台客户**（渠道协同）：已有IS-B05能碳平台客户，从"看数据"升级到"找问题"

**场景与痛点**：

| 场景 | 痛点 | 刚性 |
|:---|:---|:---:|
| 建筑外墙保温缺陷检测 | 保温层空鼓、脱落、热桥——肉眼看不到，等发现时已大面积损坏 | 🔴刚性 |
| 门窗气密性检测 | 门窗漏风是建筑能耗损失的第一大源头（50%+），人工检查效率低 | 🔴刚性 |
| 幕墙渗水检测 | 幕墙渗水导致结构安全隐患+能耗损失，传统检测需搭脚手架 | 🔴刚性 |
| 暖通空调系统诊断 | 管道保温破损、风口堵塞——人工巡检盲区多 | 🟡中等 |
| 改造效果验证（Before/After） | 节能改造后需要客观数据证明效果，否则业主不付尾款 | 🔴刚性 |

**替代方案**（用户现在怎么解决）：
1. **人工巡检+经验判读**：检测师手持热像仪，经验依赖强，3-5天/栋，不能规模化
2. **无人机热成像**：适合屋顶/高空大面，但精细部位（门窗框、幕墙接缝）无法近距离拍摄
3. **能源账单分析**：看电费/燃气费异常，但不知道具体哪里漏能——"知道自己有病，不知道病在哪"
4. **不做诊断**：等外墙损坏、漏水了再修——事后补救，损失更大

**需求评估三角形**：
- 刚性：🔴 **雪中送炭** — 既有建筑改造从"可选"变"强制"，诊断是改造的前置刚需
- 频次：🟡 **中频** — 单栋建筑1-2年/次（定期巡检），改造公司每年多项目需反复使用
- 普遍性：🔴 **广泛** — 全国600亿m²既有建筑、12万家物业公司、数千家节能改造公司

**TAM/SAM/SOM**：
- TAM（总可触达市场）：约150亿元（建筑节能改造检测+诊断服务总市场）
- SAM（可服务市场）：约50亿元（手持AI诊断仪+配套服务的建筑行业细分市场）
- SOM（可获取市场，5年）：约5亿元（基于中建体系+能碳平台客户的保守估算）

**关键假设**：
- H1（P0）：物业公司/建筑业主对"手持AI诊断仪"的付费意愿足够强（≥5000元/次或年订阅模式）
- H2（P0）：AI自动缺陷识别的准确率≥90%，能达到或超过中级检测师水平
- H3（P1）：节能改造公司愿意为"改造前诊断+改造后验证"的一体化工具支付溢价

### Step 2 解决方案

**差异化定位**：

> Flir/海康的通用热像仪是"拍照片的相机"——拍到什么要靠人眼看。HW-17是"会诊断的医生"——拍完自动告诉你哪里病了、病多重、怎么治、花多少钱。

**Sharp定位**（一句话）：
> **"沿外墙走一圈，自动出能效体检报告——冷热桥在哪、门窗漏不漏、幕墙渗没渗水，一照就知道。"**

**产品内核（做了什么、不做什么）**：

| 做 ✅ | 不做 ❌ |
|:---|:---|
| 手持热像仪+边缘AI芯片一体化 | 通用热像仪（不与Flir/海康在通用市场正面竞争） |
| 建筑缺陷自动分类：冷热桥/保温缺陷/门窗漏气/幕墙渗水 | 工业设备测温/电力巡检（不做通用场景） |
| 一键生成能效诊断报告+改造建议 | 无人机飞行平台（不做——选择手持路线，与Lamarr.AI差异化） |
| 节能效果预估（AI根据缺陷严重程度估算节能潜力） | 建筑设计/施工（不做——只诊断，给建议，不落地施工） |
| 对接能碳平台（IS-B05），实现"诊断→方案→碳核算"闭环 | 碳交易经纪/碳金融产品设计（不做——与IS-B05分工） |

│  严重程度评级：轻微/中等/严重/危险                    │

**最小可用版本（MVP）**：
1. 采购海康H21或睿创微纳CX200 Pro手持热像仪（硬件成本约1.5-3万/台）
2. 在边缘AI模块（Jetson Nano，约1000元）上部署预训练的轻量级缺陷分类模型

**增长引擎**：**黏着式 + 付费式混合**

- **黏着式**：软硬一体——买了设备用了一年，积累了历史数据，切换到另一个系统成本高。AI模型每次更新迭代，诊断准度提升，用了就离不开。
- **付费式**：早期以渠道推动为主（能碳平台客户+中建体系+住建项目），单客CAC可控。

**数据飞轮**（这是增长的更深层引擎）：
```
更多设备销售 → 更多检测数据 → 更多缺陷标注样本 → AI模型更准 → 产品竞争力更强 → 更多设备销售
```

**增长阶段**：

| 阶段 | 核心任务 | 关键指标 | 时间 |
|:---|:---|:---|:---|

| 增长早期 1-10 | 能碳平台客户转化 + 住建项目突破 | 外部客户数≥50、年度续费率≥60% | 9-18个月 |
| 加速增长 10-100 | 数据飞轮启动 + 渠道复制 | 设备年销量≥500台、CAC持续下降 | 18-36个月 |
| 继续增长 100+ | 品牌认知建立 + 海外拓展 | 市占率>30%、数据变现（诊断数据产品化） | 36个月+ |

**壁垒类型**：

| 壁垒类型 | 具体内容 | 强度 |
|:---|:---|:---:|
| **数据资产** 🔑 | 建筑缺陷标注热力图数据集（配对标注：热力图+缺陷类型+严重程度） | 🟢**强** |
| **技术壁垒** | 建筑缺陷专用AI分类模型（冷热桥/保温空鼓/门窗漏气/幕墙渗水四类缺陷的识别模型） | 🟡中（可复制但需要时间和数据） |

| **渠道壁垒** 🔑 | 能碳平台（IS-B05）现有客户关系+中建体系内部推广通道 | 🟢强（别人没有的独占渠道） |
| **品牌/资质** | 央企品牌信任背书 + 可能的检测资质/标准参与 | 🟡中 |

**可复制性评估**：
- **海康/Hikmicro复制**：**12-18个月** — 他们有热成像硬件能力和渠道，但需要(a)获取建筑缺陷标注数据(b)训练建筑专用AI模型(c)建立建筑行业客户关系。没有中建的场景和数据，这三点都不容易。
- **AI+无人机初创复制**：**难** — 他们走的是无人机路线，切换到手持路线需重新建立硬件供应链和手持端侧AI能力。
- **传统检测机构复制**：**3-5年** — 他们有经验和客户，但缺乏AI和硬件能力，数字化基因不足。
- **新进入者从零开始**：**极难** — 需要同时具备热成像硬件供应链、AI缺陷检测模型训练能力、建筑行业客户渠道、缺陷标注数据积累。中建发展的三重独占（工地场景+能碳平台客户+建筑标注数据）构成系统性壁垒。

**核心壁垒逻辑**：
> **壁垒不在热成像相机（谁都能买到），在"建筑缺陷的AI眼睛"和"能碳平台的客户耳朵"。**
> AI眼睛靠数据训出来——谁先检测1000栋建筑，谁的模型就比对手准一个数量级。
> 客户耳朵靠能碳平台（IS-B05）已有的关系——别人敲不开的门，我们已经在里面了。

**关键假设**：
- H13（P0）：建筑缺陷标注数据的积累速度足够快（12个月内至少500栋建筑的标注数据集），在海康/睿创微纳推出竞品前建立数据壁垒
- H14（P1）：能碳平台（IS-B05）的客户关系足以转化成≥30%的HW-17购买转化率

## 七、备选路径

**Plan A（首选）**：手持AI能效诊断仪 — 设备销售+软件年费
- 路径：技术POC（AI模型+边缘部署）→ 中建体系内实测 → 能碳平台客户转化 → 外部渠道拓展 → 数据飞轮
- 目标：第3年500台，收入2200万；第5年2000台，收入8000万+

**Plan B（备选1）**：检测服务平台 — 设备不卖，做诊断服务
- 路径：组建自有检测师团队 + AI辅助诊断，按栋/按项目收费
- 优势：轻资产（不需要铺硬件销售渠道）、客户决策门槛低（不需要买设备，买报告就行）
- 劣势：人效天花板低（检测师数量决定产能）、增长慢
- 目标：第3年2000栋/年，收入1600万
- **触发条件**：AI模型开发延迟超过6个月，或设备销售渠道验证失败

**Plan B'（备选2）**：纯软件模式 — AI诊断引擎Licence授权给热像仪厂商
- 路径：不做硬件，将AI缺陷检测引擎以SDK/API形式授权给海康/睿创微纳等热像仪厂商
- 优势：零硬件投入、零库存、只做软件
- 劣势：放弃硬件品牌和客户关系，沦为"卖铲子的"，长期价值被锁定
- **触发条件**：硬件OEM谈判失败，或自研硬件成本远超预期

**Plan C（退出条件）**：
- 验证期（9个月）内AI模型精度无法达到90%（vs. 中级检测师）→ 技术不成立
- 能碳平台（IS-B05）首批10家客户中，≤2家愿意采购 → 渠道假设不成立
- 海康/Hikmicro在12个月内推出"建筑能效AI诊断"专用产品 → 先发优势消失，竞争格局恶化

## 八、与IS-B05能碳平台的协同分析

**为什么HW-17是IS-B05的"杀手锏前端"**：

```
IS-B05 能碳平台（被动看数）
  │
  │  问题：能耗数据告诉你"花了多少钱"，但不知道"钱花在哪了"
  │  平台能做：能耗趋势分析、碳核算、报告生成
  │  平台不能做：定位具体缺陷、给出改造建议、估算节能潜力
  │
  ▼
HW-17 AI能效诊断仪（主动找问题）
  │
  │  问题：巡检走一圈，AI告诉你"冷热桥在3楼西南角外墙、2楼北面窗户漏风"
  │  输出：缺陷定位+严重程度+改造建议+节能预估+改造成本估算
  │
  ▼
IS-B05 + HW-17 闭环
  │
  ├── 发现问题（HW-17诊断）→ 分析问题（IS-B05关联能耗数据）
  ├── 改造方案（HW-17生成建议）→ 改造实施（节能改造公司执行）
  ├── 效果验证（HW-17复检）→ 碳核算更新（IS-B05更新碳排数据）
  └── 碳交易/绿色金融（IS-B05输出可信数据）
```

**协同价值量化**：
- IS-B05客户采购HW-17后，平台从"被动看板"升级为"主动诊断+改造+验证"闭环，客单价可从15万/年提升到25万/年（+67%）
- HW-17销售的每个客户都可以反哺IS-B05，增加能碳平台的数据维度和客户粘性

**一句话**：**IS-B05是"仪表盘"，HW-17是"听诊器"。光有仪表盘不知道引擎哪里坏了，有了听诊器才知道该修什么。**

## 九、核心风险提示

**主要风险**：

1. **AI模型精度不足风险**（P0）：建筑缺陷的视觉特征多样（不同气候区、不同建材、不同光照条件），10亿参数模型可能无法覆盖所有变异。→ 需要足够多样化的训练数据，分地域/气候区/建筑类型做模型适配。

2. **竞争窗口期风险**（P0）：海康/Hikmicro已在其热像仪中嵌入基础AI功能（测温分析/异常告警），他们距离"建筑缺陷专用AI"只差一步——拿到标注数据。→ 必须12个月内建立数据壁垒。

3. **数据获取速度风险**（P0）：500栋建筑的标注热力图数据听起来很多，实际获取可能很慢——每栋建筑需检测师标注1-2天。→ 必须设计高效的数据标注工具+激励机制（检测师众包）+合成数据增强。

4. **渠道依赖风险**（P1）：能碳平台（IS-B05）是核心渠道，如果IS-B05推进速度慢或客户反馈差，HW-17的渠道假设将受严重冲击。→ 必须同步建设独立的外部获客渠道（住建项目+行业展会）。

5. **硬件供应链风险**（P1）：OEM热像仪依赖海康/睿创微纳等供应商，如果合作中断或供应商自研竞品，硬件供应将受影响。→ 至少培育2家供应商关系，同时评估自主硬件方案可行性（利用国产红外探测器的开放供应链）。

## 十、建议下一步行动（最小验证）

**第一件事（本周）**：下载公开建筑物热成像数据集 + 在Jetson Nano上跑MobileSAM/ViT-Tiny，实测建筑缺陷分类的基础精度。

- **验证目标**：确认10亿参数级视觉模型在边缘设备上能否以≥90%精度完成冷热桥/保温缺陷/门窗漏气的基础分类
- **实验设计**：
  1. 收集公开建筑物热成像数据集（IR Buildings Dataset / 相关学术数据集）+ 中建体系内已有的外墙检测报告（如有热成像附件）
  2. 在云端用ViT-Base预训练一个建筑缺陷四分类模型（冷热桥/保温空鼓/门窗漏气/幕墙渗水）
  3. 蒸馏或直接部署到Jetson Nano，测试推理延迟+精度
  4. 如果Jetton Nano性能不足，换RK3588或直接上Jetson Orin Nano（成本增加但性能翻倍）
- **时间预算**：2周
- **人力预算**：1名AI工程师 + 1名建筑热工背景的技术顾问
- **成本预算**：Jetson Nano约1000元 + 云计算资源约2000元

**第二件事（同步启动）**：联系海康Hikmicro/睿创微纳，洽谈OEM贴牌合作 + 获取热像仪技术参数和批量报价。

- **验证目标**：确认OEM贴牌的可行性和硬件成本
- **时间预算**：2-4周（商务谈判节奏）
- **成本预算**：0（商务接触阶段）

**第三件事（第1个月内）**：从IS-B05能碳平台现有客户中选取3家，做需求访谈+概念演示。

- **验证目标**：验证"从被动看能耗→主动找缺陷"的价值主张能否打动客户
- **成功标准**：≥2家表示"这正是我们需要的东西"
- **成本预算**：0（利用现有客户关系）
