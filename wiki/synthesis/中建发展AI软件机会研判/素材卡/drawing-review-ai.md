| **操作流程** | 设计建模(导出IFC) → 模型图纸准备(一网通办) → 预检(图模一致性) → 提交智能审查 → 审图机构复核 → 在线出具合格书 |
| **双轨制** | **"智能审图+人工审查"并行**：AI生成初步审图意见，审图机构复核确认 |
| **技术要点** | BIM"一模到底"；二维三维联动审查；系统将持续结合AI/BIM发展扩展规范条文覆盖 |
| **浦东** | 可扩大适用范围、拓展审查功能，开展先行先试 |

**对中建启示**：这是目前**中国最系统化、最官方的AI审图实践**。上海模式可能成为全国模板。中建发展应密切跟踪上海BIM审图的技术标准和接口规范，确保产品合规对接。上海松江区已推行"智能审图+人工审查"双轨并行。

### 4.1 市场规模（多口径交叉验证）

| 口径 | 2025年规模 | 预测目标 | CAGR | 来源 |

| AI建筑检测（中国） | **~500亿元** | — | 45% | 行业分析文章 |

### 4.2 关键测算（Bottom-up）

```
中国每年新建建筑面积 ≈ 20亿㎡（含住宅/公建/工业）
施工图审查单价 ≈ 1-3元/㎡（因地区和项目类型而异）
传统审图市场 ≈ 20亿㎡ × 2元/㎡ = 40亿/年
  + 市政/基础设施 ≈ 10-20亿/年
  = 传统审图总市场 ≈ 50-60亿/年

AI审图替代率假设：
  2025: 渗透率<5% → ~3亿
  2027: 渗透率15-20% → ~10亿
  2030: 渗透率40-50% → ~25-30亿
```

**结论**：AI审图（设计合规审查）当前市场约**3亿**，但渗透率极低，2030年可触达**25-30亿**。若叠加BIM智能审查（上海模式）、施工方案审核（中建八局模式）、消防/节能专项审查等扩展场景，总可触达市场可达**50-80亿**。

## 六、与IS-A04（合同审查AI）的底层能力复用

AI审图与AI合同审查在底层技术栈高度重叠：

| 能力模块 | AI审图 | AI合同审查 | 可复用性 |
|:---|:---|:---|:---:|
| **文档智能** | 解析CAD图纸/BIM模型/规范文本 | 解析合同PDF/Word/扫描件 | ✅ 高 |
| **规则引擎** | 建筑规范条文数字化 → 规则库 | 合同条款模板/合规要求 → 规则库 | ✅ 高 |
| **NLP/语义理解** | 规范条文语义解析 | 合同条款语义解析 | ✅ 高 |
| **知识图谱** | 规范间引用关系/条文关联 | 法条/案例/条款关联 | ✅ 高 |
| **多模态对齐** | 图纸+规范+模型 | 招标文件+合同+投标书 | ✅ 中 |
| **CV/图形识别** | 图纸符号/线条/标注识别 | OCR/印章/签名识别 | ⚠️ 部分 |

**结论**：两个方向共享同一套"文档智能 + 规则引擎 + 知识图谱"技术底座。中建发展若同时推进两个方向，研发成本可显著摊薄。
