**利润分配**（以100元审图费拆解）

环节毛利率说明

**关键控制节点**：**数据资产型 + 政策牌照型** 双重控制。

- **数据资产**：图纸审查数据（设计院出图+审图意见+修改记录）形成闭环数据飞轮。谁掌握的审图案例越多，模型越准。

- **政策牌照**：施工图审查是政府强制环节，需要接入各地住建系统。上海BIM审查系统已是官方基础设施，后来者需对接其接口。

- **先发场景卡位**：中建体系内设计院（中建设计集团、各局设计院）的年出图量是独占审查数据入口。

**可优化环节**：传统审图人工效率极低（一份图纸审查需数天），且审图质量受个人经验影响大、覆盖率不足。AI审图可实现**10分钟级审查+规范全量覆盖**。

M3 预判稳态B

**原子级需求拆解**

用户场景解决什么问题频次愿付多少钱

**政府住建部门**区域施工图审查监管审图质量不一致、监管难度大每日100-500万/年（政府购买）

**稳态B推演**：

（国务院AI+意见要求2030年AI普及率90%）→（倒逼各省住建厅启动AI审图系统建设）→（使得上海BIM审查模式向全国复制）→（叠加湖北/安徽先行先试+中建八局已验证技术可行性）→ **中国建筑审图行业将从"纯人工审查"转向"AI初审+人工复核"的双轨制，3-5年内AI审图渗透率从<5%提升至40-50%，形成"政府平台（BIM审查）+ 商业SaaS（设计院/施工企业自检）"两层市场结构。**

**中建发展在稳态B中的位置**：

- **上层（政府平台层）**：上海BIM审查系统式的地方政府强制审查平台 — 中建不在此层直接竞争

- **下层（商业SaaS层）**：面向设计院和施工企业的"AI自检工具"—— **这是中建发展的主战场**。中建体系内设计院是天然的初始客户和训练数据来源，此优势任何竞品无法复制。

M4 Timing

**周期定位**：**早期探索 → 爆发增长的过渡期**

- 技术验证已完成：中建八局瓴维·慧审 98.6%/10分钟 → 技术可行

- 政策窗口已打开：2025年三大政策出台（国务院AI+/住建部智能建造/上海BIM审查）→ 政策启动信号明确

- 市场教育已开始：品览筑绘通150+B端客户 → 需求已验证

- **但**：尚无独立的"纯AI审图SaaS"全国性品牌 → 市场空缺

**窗口期判断**：窗口已开，还有 **2-3 年**。原因：

- 2025-2026年：湖北/安徽/上海先行先试 → 需求从"试点"到"铺开"

- 2027年：国务院AI+要求智能终端普及率70% → 采购需求集中释放

- 2030年：全面AI设计目标 → 审图作为必经环节必须同步AI化

**太早风险**：**低** — 技术已验证（瓴维·慧审 + Buildcheck + 品览），不涉及市场教育

**太晚风险**：**中高** — 品览筑绘通正在快速扩张（Q1+200%），若再不进入，2-3年后品牌心智已被占领

M5 天花板大小

**四方法交叉验证**

方法估算说明
**直接数据**中国图纸审查市场（传统+AI）≈680亿/年含政府审查费+设计院自检+施工方案审查
**Top-down**年新建20亿㎡ × 审图费2元/㎡ × AI渗透率50% = **20亿**仅施工图审查环节
**Bottom-up**设计院5000家 × 年费10万 + 审图机构300家 × 年费30万 + 施工企业2000家 × 年费5万 = **6.9亿/年**保守估算（仅SaaS订阅）
**类比法**AI合同审查（IS-A04同方向）年费市场≈10-30亿 → 审图审查体量更大图纸审查体量>合同审查

**结论**：AI审图可触达市场（TAM）约 **50-80亿元/年**（含SaaS订阅+政府项目+专项审查），支撑十亿级体量公司。若叠加BIM智能审查政府项目和扩展至消防/节能/人防等专项审查，天花板更高（100-150亿）。

M6 集中度

**现状**：**极其分散，无全国性头部玩家**

- 传统审图市场极度分散：全国300+审图机构，区域性明显

- AI审图领域：品览（设计+审图一体）有150+B端客户但定位非"纯审图"

- 中建八局瓴维·慧审是内部工具，未商业化

- **尚无独立的"AI审图SaaS"全国性品牌**

**趋势**：**C型（分散→集中）★ 最佳时机**

- 政策推动（BIM审查标准化）将统一技术标准 → 有利于形成全国性平台

- AI审图的数据飞轮效应：审图案例越多 → 模型越准 → 客户越多（典型C型逻辑）

- 2-3年内将出现AI审图头部品牌

**匹配策略**：差异化深耕 — 以中建体系内设计院为种子客户，先做"建筑行业最准的AI审图工具"，再向行业外复制。不与品览在"AI设计"正面竞争，专注"审图合规"这一定位。

**行业预判结论**：🟢 **6 模块全部通过**，进入五步法项目分析。

三、五步法逐层分析

Step 1 需求

**目标用户**（三层画像，非"所有人"）：

层级用户占比痛点刚性
**核心层**中建体系内设计院（中建设计集团、各局设计院）初始100%🔴最高 — 自家需求
**扩展层**外部大中型设计院、审图机构增长主力🔴高 — 审图效率是核心痛点
**长尾层**施工企业（方案审查）、建设单位补充收入🟡中 — 合规需求但不紧迫

**场景与痛点**：

场景痛点刚性现状替代方案
**施工图出图前自检**设计师自查难以穷举规范条文（数百本规范、数千条强条），出图后被审图机构退回修改，平均返工2-3轮、耗时1-2周🔴刚性人工校核（效率低/覆盖不全）
**施工图强制审查**审图机构人工审查一份图纸需数天，且不同审图师审查质量参差不齐，强条遗漏时有发生🔴刚性审图师人工审查（效率瓶颈）
**施工方案审查**方案中的安全计算、参数逻辑、工艺流程若出错会直接导致安全事故🔴刚性专家审核（耗时/主观/难覆盖）
**多专业协同一致性**建筑/结构/机电专业之间的图纸矛盾（如管线穿梁）难以在出图前全面发现🟡真痛点BIM碰撞检查（有工具但不智能）
**地方性规范差异**各省市有额外的规范要求，全国性设计院跨省出图时容易遗漏🟡真痛点靠设计师经验+审图机构把关

**需求评估三角形**：

- 刚性：🔴 **雪中送炭** — 审图是政府强制环节，不合规=不能开工。AI审图直接解决"会不会被退回"的刚需。

- 频次：🔴 **高频** — 每个项目施工图都需要审查，大型设计院每周都有图纸出图。

- 普遍性：🔴 **广泛** — 全国5000+设计院、300+审图机构、数万家施工企业。

**关键假设**：

- H1（P0）：设计院愿意为"AI审图SaaS"付费（而非仅使用免费BIM自带的基础检查功能）

- H2（P1）：审图机构认可AI审图结果作为正式审查依据（而非仅作"参考"）

Step 2 解决方案

**差异化定位**：

品览筑绘通是"AI帮你画图"，我们是"AI帮你审图" — **角色中立**。审图的核心价值在于"不替代设计师、不预设设计偏好"，而是以**规范为依据**进行客观合规审查。这种中立性对于审图机构（政府/第三方）尤为重要。

**核心卖点**：一句话 — **"一份图纸进去，10分钟后告诉你哪里不合规，以及为什么。"**

**Sharp定位**（用户视角）：

- 对设计院：**"不用等审图机构退回才发现问题，出图前自己跑一遍AI，一次通过率提升50%。"**

- 对审图机构：**"AI先审一遍，把90%的规范条文都检查了，你只需复核AI标记的疑点。"**

- 对施工企业：**"施工方案交上去之前，AI已经帮你检查了安全规范和参数逻辑。"**

**产品内核（做了什么、不做什么）**：

做 ✅不做 ❌
施工图多专业合规审查（建筑/结构/机电）AI生成设计方案（不与品览/小库/CONCETTO正面竞争）
规范条文→可执行规则的数字化转化替代审图师的最终签字权（AI辅助，人做最终决策）
图模一致性检查（BIM模型 vs 二维图纸）替代BIM建模工具（与广联达/PKPM互补）
施工方案安全合规审查（中建八局已验证）纯效果图渲染/AI灵感图生成
跨省地方性规范的自动匹配C端个人设计师免费工具

**产品与竞品的本质区别**：

比较维度本方案（AI审图）品览筑绘通PKPM-AID上海BIM审查
**核心定位****审**（合规审查）设计+审（一体）结构优化+审**审**（政府强制）
**角色**中立审查者设计辅助者结构优化者监管基础设施
**关键差异**不替代设计师、专注审图设计生成是主线结构专业为主官方平台非SaaS
**目标用户**设计院+审图机构设计师+设计院结构工程师政府审图

**最小可用版本（MVP）**：

1. 接入中建设计集团一个专业（建筑）的100份历史施工图 + 对应的审图意见

2. 将50条最常违规的建筑强制性条文转化为可执行规则

3. 用瓴维·慧审的大模型+知识图谱技术底座做规则匹配

4. 输入新图纸 → 自动输出违规清单 + 条文对照 + 修改建议

5. 在中建设计集团内部跑通"出图→AI自检→修改→提交审图"闭环

**关键假设**：

- H3（P0）：AI审图的准确率（召回率）能达到审图机构接受的水平（≥95%）

- H4（P1）：规范条文能用NLP+知识图谱技术高效转化为可执行规则（转化成本可控）

七、备选路径

**Plan A（首选）**：独立AI审图SaaS — 专注合规审查

- 路径：中建体系内验证 → 外部设计院横向复制 → 审图机构接入 → 政府BIM审查对接

- 目标：第3年收入1575万，第5年5000-8000万

- 核心差异：中立审图者（不替代设计师）

**Plan B（备选）**：与IS-A04合同审查合并为"AI文档合规审查平台"

- 路径：将AI审图+AI合同审查整合为一个技术底座的"建筑行业文档合规审查平台"

- 优势：共享技术底座（文档智能+规则引擎+知识图谱），研发成本摊薄40-50%；交叉销售（同一家设计院既审图也审合同）

- 目标：两个方向合并后第3年收入3000万+，第5年1亿+

- 风险：组织复杂度增加，两个方向可能相互拉扯资源

**Plan C（备选）**：嵌入BIM平台成为"审图插件"

- 路径：不做独立SaaS，而是将AI审图引擎封装为API/SDK，嵌入广联达BIM/PKPM等平台

- 优势：轻资产、借力平台分发、无需自建获客体系

- 劣势：收入天花板低（分润模式）、品牌依附平台、谈判议价权弱

- 目标：第3年API收入300-500万

**Plan D（退出条件）**：

- 验证期内（6个月）中建体系内≥3家设计院拒绝日常使用 → 内部需求不成立

- AI审图准确率<90%且无改善路径 → 技术不可行

- 规范数字化成本远超预期（>100万/年维护）→ 经济不可行

- 品览/广联达在审图方向推出类似产品且已经获得50+设计院客户 → 窗口期关闭

八、建议下一步行动（最小验证）

**第一件事（本周）**：在中建设计集团选择1个专业（建筑），用50份历史施工图 + 审图意见做一次AI审图准确率验证

- **验证目标**：AI模型能否在50份图纸上，召回≥90%的审图意见中标注的违规项

- **实验设计**：

1. 从设计集团调取50份近1年已审查通过的施工图 + 对应的审图意见（含退回修改项）

2. 提取审图意见中最常见的TOP 30条建筑强制性条文

3. 用瓴维·慧审的技术底座（Transformer大模型+知识图谱）将这些条文转化为可执行规则

4. 输入原始图纸（审图前版本）→ AI输出违规清单

5. 对比AI违规清单 vs 审图机构实际标记的违规项 → 计算准确率/召回率/误报率

- **成本预算**：2周时间 + 1名AI工程师 + 1名建筑专业注册工程师 + 0元外部采购（数据已有）

- **成功标准**：召回率（AI发现的实际违规占比）≥ 90%，误报率 ≤ 30%
