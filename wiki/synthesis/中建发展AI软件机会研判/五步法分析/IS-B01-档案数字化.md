## 二、行业预判（六模块）

### M1 拆解行业

**产业链图**

```
硬件/基础设施          技术/算法层              服务/应用层              终端用户
扫描仪/高拍仪    ──→   AI-OCR算法厂商    ──→   档案数字化加工服务  ──→   央企组织人事部
昇腾/寒武纪芯片  ──→   信创适配中间件    ──→   AI专审系统SaaS     ──→   国企档案管理部门
                       大模型厂商        ──→   信创部署集成服务    ──→   纪检监察部门
```

**利润分配**（100元收入拆解）

| 环节 | 毛利率 | 说明 |
|:---|:---:|:---|
| 硬件设备（扫描仪/芯片） | 20-30% | 标准化硬件，利润透明 |
| 档案数字化加工服务 | 30-40% | 劳动密集型，人力成本占比高 |
| AI-OCR算法+专审系统 | 60-70% | 软件性质，边际成本极低 |
| 信创部署集成 | 40-50% | 适配调试成本一次性投入 |

**关键控制节点**：**技术壁垒型** — AI-OCR在干部档案专用场景的准确率（99.2%）+ 信创全栈适配能力（昇腾/寒武纪/飞腾/鲲鹏）是核心竞争力。航星永志之所以成为"一超"，正是因为同时掌握了档案行业Know-how和AI技术。

**可优化环节**：央企干部档案审核长期依赖人工（每卷审核需数小时），AI可将审核用时压减60%以上。济南标杆已验证：超10万卷干部档案，52类核心数据元素，AI初审+人工复审模式。

### M2 洞察变化

| 维度 | 变化 | 量级 | 证据 |
|:---|:---|:---:|:---|
| **政策法规** | "凡提必审、凡进必审、凡转必审"硬性要求 | 🔴大 | 《干部人事档案工作条例》 |
| **政策法规** | 国资委79号文：2027年前央企核心系统100%信创替代 | 🔴大 | 央企合规刚需，无弹性 |
| **新技术** | AI-OCR专用模型：22类材料3秒完成，准确率99.2% | 🟡中 | 技术已成熟，关键在行业适配 |
| **新技术** | AI专审：济南标杆验证，审核用时压减60%+，准确率97%+ | 🟡中 | 10万卷+验证，可复制 |
| **需求侧** | 央企干部档案数字化存量市场：数十亿至百亿级 | 🔴大 | 央企数量×档案卷数×单卷价格 |
| **供给侧** | 航星永志年营收约10亿，已推出AI专审机器人 | 🟡中 | 头部已布局，但市场渗透率仍低 |

**判断**：这是一个**系统性变化** — 政策（凡提必审+信创强制）+ 技术（AI-OCR+AI专审成熟）+ 需求（央企存量档案数字化）三重共振。双重刚需叠加，需求弹性极低。

### M3 预判稳态B

**原子级需求拆解**

| 用户 | 场景 | 解决什么问题 | 愿付多少钱 |
|:---|:---|:---|:---|
| 央企组织人事部 | 干部提拔前档案专审 | 人工审核效率低（每卷数小时）、易遗漏 | 50-200万/项目 |
| 央企档案管理部门 | 存量档案数字化加工 | 纸质档案无法检索、无法AI分析 | 按卷数计费，2-5元/页 |
| 央企IT/信创部门 | 信创环境部署 | 国资委2027年信创替代硬性要求 | 含在项目总价中 |
| 纪检监察部门 | 干部档案合规审查 | "三龄两历一身份"人工校核效率低 | 30-100万/年 |

**稳态B推演**：

> （凡提必审+信创强制双重政策驱动）→（使得AI档案专审+信创部署成为央企合规刚需）→（叠加AI-OCR技术成熟）→ **央企干部档案管理从"人工+传统OCR"转向"AI专审+信创部署"，头部企业凭借技术+行业Know-how+客户信任形成壁垒。**

**中建发展在稳态B中的位置**：**技术+信创的差异化挑战者** — 管理学院项目已验证交付能力（中建AI第一单），昇腾信创适配已跑通，但面对航星永志（年营收10亿、20年深耕、32个省级网络）的先发优势，需找到差异化切入点。

### M4 Timing

**周期定位**：**早期探索 → 爆发增长的过渡期**

- 政策已明确（凡提必审+信创2027大限），需求确定性高
- AI-OCR/AI专审技术已成熟，济南标杆已验证
- 但市场渗透率仍低，多数央企仍在用人工或传统方案

**窗口期判断**：窗口已开，还有 **2-3 年**。原因：
- 信创2027年大限倒逼，央企必须在此之前完成核心系统信创替代
- 航星永志等头部正在加速"AI+信创"转型，先发优势在扩大
- 中建发展已有管理学院标杆，但尚未形成规模化复制能力

**太早风险**：低 — 技术已成熟，政策已明确，管理学院项目已验证
**太晚风险**：高 — 航星永志32个省级网络+20年客户关系，窗口期有限

### M5 天花板大小

**四方法交叉验证**

| 方法 | 估算 | 说明 |
|:---|:---|:---|
| **直接数据** | 档案数字化（狭义）284.6亿(2025)，同比+23.7% | 仅加工服务市场 |
| **直接数据** | AI+档案库房（广义）880亿(2025) | 含智能库房、AI审核等 |
| **Top-down** | 央企数量×平均档案卷数×单卷数字化+审核价格 = 数十亿至百亿级 | 仅央企干部档案 |
| **类比法** | 信创产业2023年2.1万亿→2027年3.7万亿 | 档案管理是信创落地场景之一 |

**结论**：央企干部档案数字化可触达市场 **50-100亿元**，叠加信创部署和AI专审，支撑十亿级体量公司。但相比供应商风控（50-200亿），天花板略低。

### M6 集中度

**现状**：**有头部玩家但未形成垄断**
- 航星永志：年营收约10亿，32个省级网络，专精特新"小巨人"，客户覆盖中宣部/外交部/国资委
- 紫光集团：第一梯队，综合实力最强
- 其他：市场呈"一超多强"格局，但尚未出现全国性垄断

**趋势**：**C型（分散→集中）**
- 政策驱动（信创2027大限）将加速行业整合
- 技术壁垒（AI-OCR+信创适配）提高进入门槛
- 客户信任是关键壁垒（干部档案数据极敏感）

**匹配策略**：差异化深耕 — 不与航星永志在通用档案市场正面竞争，而是聚焦"央企AI专审+信创部署"细分场景，利用中建体系内客户关系和昇腾信创适配能力做差异化切入。

**行业预判结论**：🟡 5 模块通过（M5天花板略低），补充待验证假设后进入五步法项目分析。

## 三、五步法逐层分析

### Step 1 需求

**目标用户**：央企/国企组织人事部门、档案管理部门（非"所有人"）

**场景与痛点**：

| 场景 | 痛点 | 刚性 |
|:---|:---|:---:|
| 干部提拔前档案专审 | 人工审核每卷需数小时，52类核心数据元素逐一校核，效率低、易遗漏 | 🔴刚性（凡提必审） |
| 存量档案数字化 | 纸质档案无法检索、无法AI分析，历史数据沉淀浪费 | 🟡中等（锦上添花） |
| 信创环境部署 | 国资委2027年信创替代硬性要求，不合规则问责 | 🔴刚性（政策强制） |
| "三龄两历一身份"校核 | 人工校核效率低、主观性强、覆盖面窄 | 🔴刚性（凡提必审） |

**替代方案**：
- 航星永志AI专审机器人（已有产品，年营收10亿，客户覆盖广）
- 传统OCR软件（非AI，准确率低，无法理解语义）
- 人工审核（效率低，但"不出错"是组织人事部门的底线要求）

**需求评估三角形**：
- 刚性：🔴 雪中送炭 — 凡提必审+信创强制，双重政策刚需
- 频次：🟡 中频 — 每次干部任免都需要，但非每日高频
- 普遍性：🔴 广泛 — 所有央企国企都有需求

**关键假设**：
- H1（P0）：央企组织人事部门愿意为"AI专审+信创部署"一体化方案付费（而非分别采购）
- H2（P1）：中建发展能在2-3年内建立足够的客户信任（干部档案数据极敏感）

### Step 2 解决方案

**差异化定位**：

> 航星永志是"档案行业老兵"（20年深耕、32个省级网络），我们是"AI+信创的央企内部人" — 区别在于：我们有**昇腾信创全栈适配能力**（航星永志的信创适配仍在进行中）+ **中建体系内央企客户信任**（管理学院已验证交付能力）。

**核心卖点**：一句话 — **"22类干部档案材料，3秒完成识别，准确率99.2%，信创全适配。"**

**产品内核（做了什么、不做什么）**：

| 做 ✅ | 不做 ❌ |
|:---|:---|
| 干部档案AI专审（三龄两历一身份自动校核） | 通用档案数字化加工（劳动密集型，与航星永志正面竞争） |
| AI-OCR专用模型（22类干部档案材料） | 通用OCR（与百度/腾讯等大厂竞争） |
| 昇腾信创全栈部署 | 非信创环境部署（不与传统IT集成商竞争） |
| 人机协同审核（AI初审+人工复审） | 完全替代人工（组织人事部门不接受"黑箱"） |

**最小可用版本（MVP）**：
1. 基于管理学院项目经验，提炼"AI专审+信创部署"标准方案
2. 选择1家中建体系内工程局做第二个标杆
3. 验证方案可复制性（非定制化）

**关键假设**：
- H3（P0）：中建体系内其他工程局有干部档案AI专审需求（管理学院不是个例）
- H4（P1）：AI-OCR专用模型在不同央企的档案格式上准确率保持97%+

### Step 3 商业模式

**单元模型选型**：**单客户（项目制ToB）** — 按项目交付+年度运维混合计费

**收入测算**：

| 收入来源 | 单价 | 客户基数（第3年） | 年收入 |
|:---|:---|:---|:---|
| 央企AI专审+信创部署（标准版） | 100万/项目 × 5家 | 中建系+其他央企 | 500万 |
| 档案数字化加工（附属服务） | 30万/项目 × 10家 | 存量档案数字化需求 | 300万 |
| 年度运维+模型迭代 | 20万/年 × 8家 | 已交付客户 | 160万 |
| **第3年合计** | | | **960万** |

| 技术团队（AI算法+信创工程） | 400万 | 6-8人，含OCR模型迭代 |

- H6（P2）：年度运维续约率≥70%

### Step 4 增长

**获客渠道清单**（优先级排序）：

| 优先级 | 渠道 | 预估CAC | 说明 |
|:---:|:---|:---:|:---|
| 1 | **中建体系内复制** | 0（内部推广） | 8个工程局+N个子公司，管理学院标杆背书 |
| 2 | **央企集团总部渠道** | 5-10万 | 通过国资委/央企集团总部推广到下属单位 |
| 3 | **行业协会/政府渠道** | 10-15万 | 中国档案学会、各地档案局 |
| 4 | **信创生态合作** | 8-12万 | 与华为昇腾/中国电子等信创厂商联合推广 |
| 5 | **内容营销+行业会议** | 15-20万 | 档案数字化峰会、白皮书、案例分享 |

**增长引擎**：**黏着式** — AI专审系统嵌入组织人事流程后，切换成本高（数据迁移+流程重建+人员培训）

**增长阶段**：

| 阶段 | 核心任务 | 关键指标 | 时间 |
|:---|:---|:---|:---|
| 商业验证 0-1 | 中建体系内第二个标杆项目 | 内部NPS、模型准确率 | 0-6个月 |
| 增长早期 1-10 | 央企横向复制（3-5家） | 外部客户数、项目交付周期 | 6-18个月 |
| 加速增长 10-100 | 信创生态合作+行业协会渠道 | CAC趋势、客户增速 | 18-36个月 |

**关键假设**：
- H7（P0）：中建体系内各局愿意使用中建智能的AI专审方案（而非航星永志）
- H8（P1）：其他央企愿意接受"中建系"的档案AI方案（竞争关系顾虑）

### Step 5 壁垒

**壁垒类型**：

| 壁垒类型 | 具体内容 | 强度 |
|:---|:---|:---:|
| **技术壁垒** | AI-OCR专用模型（22类材料99.2%准确率）+ 昇腾信创全栈适配 | 🟡中 |
| **转化成本** | 嵌入组织人事流程后，切换成本高（数据迁移+流程重建+人员培训） | 🟡中 |
| **无形资产** | 央企身份+中建品牌背书+管理学院标杆案例 | 🟡中 |
| **规模效应** | 模型训练成本被客户数摊薄，但当前客户基数小 | 🔴弱 |
| **网络效应** | 无 — 档案AI专审是单客户产品，无网络效应 | 🔴无 |
| **成本优势** | 无独占资源或地理位置优势 | 🔴无 |

**可复制性评估**：
- 航星永志复制信创适配：**1-2年** — 航星永志已有AI专审产品，信创适配是工程问题，非技术壁垒
- 其他央企复制：**2-3年** — 需要同时具备AI技术+档案行业Know-how+信创适配能力
- 新进入者复制：**3年+** — 需要积累客户信任（干部档案数据极敏感）

**核心风险**：航星永志是最大的竞争威胁 — 年营收10亿、20年深耕、32个省级网络、已推出AI专审机器人。中建发展的差异化在于信创适配和央企内部信任，但这些壁垒的持续性存疑。

## 七、备选路径

**Plan A（首选）**：央企AI专审+信创部署一体化方案
- 路径：中建体系内标杆 → 央企横向复制 → 信创生态合作 → 行业标准制定
- 目标：第3年收入960万，第5年收入5000万+

**Plan B（备选）**：AI-OCR技术输出（不做集成，只做算法授权）
- 路径：将AI-OCR专用模型封装为API/SDK，授权给航星永志等档案服务商
- 优势：更轻资产，无需ToB销售团队和项目交付能力，直接技术变现
- 风险：航星永志可能自研替代，技术授权天花板低
- 目标：第3年3-5家授权客户，API收入300万/年

**Plan C（退出条件）**：
- 验证期内（6个月）中建体系内≥3个工程局明确表示无需求 → 内部需求不成立
- 航星永志在1年内完成信创全栈适配 → 差异化壁垒消失
- AI-OCR专用模型在不同央企档案格式上准确率<95% → 技术方案不成立
- 信创适配成本持续高于80人天/项目 → 毛利无法改善

## 八、建议下一步行动（最小验证）

**第一件事（本周）**：在中建体系内选择 1 个工程局的组织人事部门，做一次干部档案AI专审需求验证

- **验证目标**：确认该局是否存在干部档案AI专审需求，以及是否愿意使用中建智能的方案（而非航星永志）
- **实验设计**：
  1. 访谈该局组织人事部门负责人，了解当前档案审核流程和痛点

  3. 确认该局是否有信创部署需求和预算
  4. 收集该局档案格式和数据量信息，评估AI-OCR模型适配难度
- **成本预算**：1 周时间 + 1 名BD人员 + 0 元技术投入
- **成功标准**：该局明确表达"有兴趣试点"或"愿意进一步沟通"

## 九、与供应商智能风控（SC-01）的对比

| 维度 | 供应商智能风控（SC-01） | 档案数字化（IS-B01） |
|:---|:---|:---|
| **硬伤评分** | 5/20（低风险） | 6/20（低风险） |
| **核心壁垒** | 数据资产（10万亿交易数据）🟢强 | 技术+信创适配 🟡中 |
| **竞争格局** | 无直接竞品（建筑垂直空白） | 航星永志年营收10亿（强敌在前） |
| **天花板** | 50-200亿 | 50-100亿 |
| **增长引擎** | 黏着式+网络效应 | 黏着式（无网络效应） |
| **最大风险** | 数据合规（P0） | 航星永志先发优势+客户信任建立周期长 |

**结论**：IS-B01（档案数字化）的风险略高于SC-01（供应商智能风控），主要因为航星永志的先发优势和客户信任壁垒。但IS-B01的政策确定性更强（凡提必审+信创强制双重刚需），且已有管理学院标杆验证。建议作为"稳健型"机会推进，优先在中建体系内建立第二个标杆，再考虑外部复制。
