## 二、行业预判（六模块）

### M1 拆解行业

**产业链图**

```
文档输入层              AI处理层                应用层                终端用户
多语言标书/合同   ──→  多语言文档解析    ──→  投标文件智能审查   ──→  海外投标团队
技术规范/法规     ──→  条款风险识别      ──→  合规性自动校验     ──→  法务合规部门
历史投标案例      ──→  知识图谱匹配      ──→  投标策略建议       ──→  海外业务管理层
```

**利润分配**（100元收入拆解）

| 环节 | 毛利率 | 说明 |
|:---|:---:|:---|
| AI模型研发与训练 | 60-70% | 核心算法团队成本，边际成本极低 |
| 多语言NLP引擎 | 50-60% | 语种覆盖越多，边际成本越低 |
| 产品化与私有部署 | 40-50% | 央企私有化部署要求，定制化拉低毛利 |
| 销售与实施 | 20-30% | 内部推广成本低，外部获客成本高 |

**关键控制节点**：**场景知识型** — 海外投标评审的核心壁垒不是通用NLP能力，而是对国际工程EPC合同条款、FIDIC条款体系、多国法律法规的深度理解。这是通用AI文档审查产品（如幂律智能MeCheck）难以覆盖的行业know-how。

**可优化环节**：海外投标团队长期依赖人工审查（3-5个工作日/份），多语言文档审查效率极低、风险遗漏率高。国际工程争议中约35%与合同条款理解差异直接相关。

### M2 洞察变化

| 维度 | 变化 | 量级 | 证据 |
|:---|:---|:---:|:---|
| **政策法规** | 国资委推动央企"穿透式监管"，国际工程合规要求日益严格 | 🔴大 | 国资委46号令（2025年11月发布，2026年1月施行）规定了98种违规追责情形（原37号令72种扩展而来），近年持续强化"应追尽追" |
| **需求侧** | 中建海外业务快速增长，2025年境外营收1,416.98亿元（+22.20%） | 🔴大 | 海外投标量持续增加，人工审查瓶颈明显 |
| **需求侧** | 境外营收占比仅5-6%，对标中国电建（34.5%）有巨大提升空间 | 🔴大 | 海外扩张将持续带来更多投标评审需求 |
| **新技术** | 大模型多语言能力成熟，AI审查准确率>95% | 🟡中 | 审查周期从3-5天缩至15-25分钟 |
| **新技术** | 多语言文档解析技术成熟，支持30+语种 | 🟡中 | BidBooster、RWS等已有成熟产品 |
| **供给侧** | 竞品已出现但未深度渗透建筑央企 | 🟡中 | BidBooster/TextIn/Allybee等面向通用市场 |

**判断**：这是一个**系统性变化** — 政策（穿透式监管）+ 需求（海外业务高速增长）+ 技术（大模型多语言能力成熟）三重共振。变化量级足以支撑十亿级体量的内部产品线。

### M3 预判稳态B

**原子级需求拆解**

| 用户 | 场景 | 解决什么问题 | 愿付多少钱 |
|:---|:---|:---|:---|
| 海外投标团队 | 投标文件审查 | 多语言标书审查周期长、风险遗漏 | 5-15万/年 |
| 法务合规部门 | 合同条款合规审查 | 国际工程合同条款复杂，人工审查易遗漏 | 含在订阅中 |
| 海外业务管理层 | 投标风险总览 | 缺乏全局风险视图，决策依赖经验 | 10-30万/年 |
| 区域公司（如中建中东） | 本地化合规审查 | 各国法规差异大，本地化合规成本高 | 5-10万/年 |

**稳态B推演**：

> （国资委穿透式监管+海外业务高速增长）→（使得多语言投标AI审查成为合规刚需）→（叠加AI多语言技术成熟）→ **海外投标评审从"人工经验驱动"转向"AI+规则驱动"，集团内部平台凭借行业场景知识和集团背书形成标准化输出。**

**中建发展在稳态B中的位置**：集团内部唯一的海外投标AI审查平台供应商 — 已有集团海外部交付经验，掌握国际工程EPC合同条款、FIDIC体系等行业know-how，可横向复制至所有海外机构。

### M4 Timing

**周期定位**：**早期探索 → 爆发增长的过渡期**

- 通用AI文档审查产品（幂律智能MeCheck、TextIn等）已完成市场教育
- 建筑行业海外投标垂直的AI审查尚处早期，竞品多面向通用合同审查
- 中建智能已有技术版本交付集团海外部，处于内部验证→横向复制的关键节点

**窗口期判断**：窗口已开，还有 **2-3 年**。原因：
- 国资委穿透式监管要求持续推进，2026-2027年合规需求集中爆发
- 中建海外业务高速增长（2026Q1境外新签+9.5%），投标量持续增加
- 竞品（BidBooster/TextIn）正在向建筑行业渗透，但缺乏行业场景深度

**太早风险**：低 — 技术版本已交付集团海外部，已有真实业务场景验证
**太晚风险**：中 — 通用AI文档审查产品正在向垂直行业扩展，若不尽快占据集团内部市场，外部产品可能渗透

### M5 天花板大小

**四方法交叉验证**

| 方法 | 估算 | 说明 |
|:---|:---|:---|
| **直接数据** | AI文档审查市场全球33.2亿美元(2025)→43亿美元(2026) | +29.6%，含全行业 |
| **Top-down** | 中建海外营收1,416亿 × 投标审查服务费率0.1-0.3% = 1.4-4.3亿 | 仅中建体系内 |
| **Bottom-up** | 10-15个可复制节点 × 年均50-100万/节点 = 500-1500万 | 保守估算，仅中建体系内 |
| **类比法** | 幂律智能MeCheck央企级数十万-百万/年 → 中建体系内至少同等体量 | 差异化场景 |

**结论**：中建体系内海外投标AI审查可触达市场 **5000万-1.5亿元**，若扩展至其他建筑央企（中铁/中交/中铁建等海外业务），天花板可达 **5-10亿元**。

### M6 集中度

**现状**：**有头部玩家但未形成建筑行业垄断**
- 通用层：幂律智能MeCheck、合合信息TextIn、BidBooster等在通用合同审查市场有布局
- 建筑垂直层：无全国性建筑行业海外投标AI审查寡头
- 中建体系内：中建智能是唯一已有交付经验的供应商

**趋势**：**C型（分散→集中）★ 最佳时机**
- 行业场景知识（EPC合同/FIDIC条款/多国法规）具有壁垒效应
- 政策推动（穿透式监管）将加速央企采购AI审查工具
- 2-3年内将出现建筑行业海外投标AI审查的头部产品

**匹配策略**：差异化深耕 — 利用中建体系内的行业场景知识和集团背书，在建筑央企内部做深做透，而非与通用AI文档审查产品正面竞争。

**行业预判结论**：🟢 6 模块全部通过，进入五步法项目分析。

## 三、五步法逐层分析

### Step 1 需求

**目标用户**：中建体系内海外业务单位（海外部、中建国际、八局国际等），非"所有人"

**场景与痛点**：

| 场景 | 痛点 | 刚性 |
|:---|:---|:---:|
| 多语言投标文件审查 | 30+语种标书人工审查周期3-5天，效率低、风险遗漏 | 🔴刚性 |
| 国际工程合同条款审查 | FIDIC条款复杂，人工审查易遗漏关键风险点 | 🔴刚性 |
| 多国法规合规校验 | 30+国家法规差异大，本地化合规成本高 | 🔴刚性 |
| 投标风险全局视图 | 缺乏跨项目、跨区域的风险总览，决策依赖经验 | 🟡中等 |

**替代方案**：人工审查（效率低、主观性强）、通用AI文档审查产品（幂律智能MeCheck等，缺乏建筑行业场景深度）

**需求评估三角形**：
- 刚性：🔴 雪中送炭 — 政策合规刚需（穿透式监管）+ 业务增长驱动（海外营收+22%）
- 频次：🔴 高频 — 每次海外投标都需要多语言文件审查
- 普遍性：🔴 广泛 — 所有海外业务单位都有需求（25家海外机构+42个驻外机构）

**关键假设**：
- H1（P0）：各海外机构愿意使用集团统一的AI投标审查平台（而非自建或外采通用产品）
- H2（P1）：AI审查准确率能覆盖80%以上的常见风险点（剩余20%需人工复核）

### Step 2 解决方案

**差异化定位**：

> 幂律智能MeCheck/TextIn是"通用合同AI审查工具"，我们是"建筑行业海外投标专属AI审查平台" — 区别在于：我们有**国际工程EPC合同条款+FIDIC体系+多国建筑法规的行业know-how**，能回答"这个投标文件在国际工程场景下有什么风险"，而通用产品只能回答"这个合同在法律层面有没有问题"。

**核心卖点**：一句话 — **"通用工具审法律条款，我们审国际工程风险。"**

**产品内核（做了什么、不做什么）**：

| 做 ✅                | 不做 ❌              |
| :----------------- | :---------------- |
| 多语言投标文件智能审查（30+语种） | 通用合同审查（与幂律智能正面竞争） |
| FIDIC条款风险识别与合规校验   | 国内工程投标审查（专注海外）    |
| 多国建筑法规合规性自动校验      | 翻译服务（专注审查，不做纯翻译）  |
| 投标风险全局视图与决策支持      | 项目管理系统（专注审查环节）    |

**最小可用版本（MVP）**：
1. 基于集团海外部已有系统，固化核心审查规则
2. 扩展支持中建国际、八局国际的业务场景
3. 输出标准化审查报告（风险等级+建议措施）
4. 嵌入海外投标流程做内部验证

**关键假设**：
- H3（P0）：已有系统的审查规则能覆盖各海外机构80%以上的常见场景
- H4（P1）：大模型多语言能力能准确理解30+语种的专业工程术语

### Step 3 商业模式

**单元模型选型**：**单客户（ToB SaaS/私有化部署）** — 按机构年订阅 + 按审查份数混合计费

- 3人团队轻量启动，算力成本由中建数科承担 → **从一开始就是正向盈利**
- 无需外部融资、无需集团特殊政策，自身盈利即可滚动发展

### Step 4 增长

**增长路径：不是"卖更多一样的客户"，而是"从入口向深处走"**

IS-A01的增长逻辑跟其他方向不同——它不是靠扩大客户数来实现增长，而是靠**单客户价值的持续提升**。具体三条路径：

**路径一：纵向深挖（从投标到全流程）**
海外部投标审查是入口，进去之后可以沿业务链条延伸：
```
投标审查 → 合同管理 → 履约监控 → 索赔辅助 → 竣工结算
```
每深一步，嵌入程度就深一层，替换成本就高一级。不需要重新获客，同一批客户群做深做透。

**路径二：横向复制（从海外部到各职能部门）**
海外部做成后，法务部（合同审查）、采购部（供应商条款审查）、市场部（投标策略分析）可以复用同一技术底座，同样不需要重新获客。

**路径三：生态联动（培训+硬件延伸）**
- **培训联动**：与管理学院合作，将AI审标书案例做成培训项目。AI工具嵌入业务流 → 员工用AI提效 → 实操经验沉淀为培训案例 → 培训教人用好AI，形成增强回路
- **硬件延伸**：海外工地网络差，如果出现离线AI终端需求（加固平板本地跑模型），是业务需要长出来的硬件，不是为做硬件而做硬件

**增长引擎**：**黏着式** — 投标审查是嵌入海外投标流程的基础设施，用了就离不开

**增长阶段**：

| 阶段 | 核心任务 | 关键指标 | 时间 |
|:---|:---|:---|:---|
| 商业验证 0-1（已完成） | 集团海外部已交付运行 | 审查准确率、用户满意度 | ✅ 已完成 |
| 增长早期 1-10 | 中建国际+八局国际复制 | 覆盖机构数、审查量 | 6-18个月 |
| 加速增长 10-100 | 全集团机构覆盖+职能部门扩展 | 单客户ARPU提升 | 18-36个月 |

**关键假设**：
- H7（P0）：集团层面愿意发文推动各海外机构统一使用
- H8（P1）：各海外机构愿意放弃自建/外采，使用集团统一平台

### Step 5 壁垒

**壁垒类型**：

| 壁垒类型 | 具体内容 | 强度 |
|:---|:---|:---:|
| **行业场景知识** 🔑 | 国际工程EPC合同+FIDIC条款+多国建筑法规的深度理解 | 🟢强 |
| **转化成本** | 嵌入投标流程后，审查规则+历史数据积累形成粘性 | 🟢强 |
| **无形资产** | 集团海外部背书+央企身份 | 🟡中 |
| **规模效应** | 规则库+语料库随客户增长持续积累，边际成本趋零 | 🟡中 |
| **网络效应** | 弱 — 内部系统，客户间数据不互通 | 🔴弱 |

**可复制性评估**：
- 幂律智能/TextIn复制：**中等** — 通用AI能力强，但缺乏建筑行业海外投标场景深度，需1-2年积累
- 其他建筑央企复制：**2-3年** — 中铁/中交等有海外业务，但缺乏中建智能已有的技术积累和集团背书
- 新进入者复制：**难** — 需要同时具备行业场景知识+多语言NLP能力+央企客户基础

**关键假设**：
- H9（P1）：行业场景知识（EPC/FIDIC/多国法规）能形成有效壁垒，竞品短期内难以复制

## 七、备选路径

**Plan A（首选）**：建筑行业海外投标AI审查平台（集团内部标准化输出）
- 路径：集团海外部验证 → 中建国际复制 → 全集团覆盖 → 外部央企探索
- 目标：第3年收入460万，第5年收入1500万+

**Plan B（备选）**：多语言文档审查能力模块化输出（不做平台，只做能力组件）
- 路径：将多语言审查能力封装为API/SDK，嵌入各海外机构现有系统
- 优势：更轻量，无需替换现有系统，降低推广阻力
- 目标：第3年10个节点API调用收入300万/年

**Plan C（退出条件）**：
- 验证期内（6个月）≥3个海外机构拒绝使用 → 内部需求不成立
- 集团层面不愿发文推动 → 缺乏行政驱动力，推广周期大幅延长
- AI审查准确率无法达到80% → 产品内核不成立

## 八、建议下一步行动（最小验证）

**第一件事（本周）**：在中建国际建设选择 1 个驻外机构（如中建中东），用已有系统做一次真实投标文件审查测试

- **验证目标**：已有审查规则对该机构业务场景的覆盖率是否≥80%，AI审查准确率是否≥90%
- **实验设计**：
  1. 选取该机构近 6 个月的 20 份投标文件（含 5 份已知存在风险的文件）
  2. 用已有系统做自动审查，输出风险点清单
  3. 与人工审查结果对比，计算覆盖率/准确率/误报率
  4. 收集投标团队使用反馈（易用性、效率提升感知）
- **成本预算**：2 周时间 + 1 名NLP工程师 + 0 元外部采购（系统已就绪）
- **成功标准**：覆盖率≥80%，准确率≥90%，用户满意度≥4/5分

## 九、与办公厅制度审核（IS-A02）的协同关系

海外部投标评审（IS-A01）与办公厅制度审核（IS-A02）是**同一技术底座的两个应用场景**：

```
技术底座：多语言文档智能审查引擎
  │
  ├── IS-A01 海外部投标评审（国际化场景）
  │     ├── 多语言标书审查
  │     ├── FIDIC条款风险识别
  │     └── 多国法规合规校验
  │
  └── IS-A02 办公厅制度审核（国内场景）
        ├── 制度文件版本比对
        ├── 合规性自动校验
        └── 差异高亮展示
```

**建议**：IS-A01 和 IS-A02 应共享同一套文档审查引擎 — IS-A01 积累多语言和国际法规能力，IS-A02 积累中文制度审核能力。两者边际成本极低，可形成"国内+国际"双轮驱动的产品矩阵。

### 入口竞争与市场边界分析（复审补充·2026-06-16）

**市场天花板约束**

IS-A01不是平台级机会，而是内部工具型产品。中建体系内天花板5000万-1.5亿，扩展至其他央企5-10亿。这个天花板由两个因素决定：
1. **集团发文依赖**：H7假设"集团层面愿意发文推动"是P0级假设，但集团发文的决策周期通常6-12个月，且各海外机构的执行力度差异大
2. **外部获客难度**：其他央企有自己的海外业务管理系统，替换成本高

**竞品边界**

| 竞品类型 | 代表 | 威胁等级 | 说明 |
|:---|:---|:---:|:---|
| 通用AI文档审查 | ChatGPT/Claude企业版 | 🟢低 | 通用模型无法理解FIDIC/各国建筑法规的专业语境 |
| 工程咨询公司 | 奥雅纳/AECOM | 🟡中 | 传统咨询服务可能叠加AI工具提升效率 |
| 法律科技公司 | 幂律智能 | 🟡中 | 法律AI从合同审查延伸到投标文件审查是自然方向 |
| 央企自研 | 中铁/中交自建 | 🟡中 | 各央企可能自研海外投标AI，但行业know-how积累需要时间 |

**合规风险补充**：涉及欧盟业务的海外机构需遵守GDPR。投标文件中可能包含个人数据（项目经理简历、业绩证明等），AI处理这些数据需要额外的合规评估。建议在产品设计中增加数据脱敏模块。
