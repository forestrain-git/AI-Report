## 二、行业预判（六模块）

### M1 拆解行业

**产业链图**

```
数据采集层              平台/算法层              应用层                终端用户
建筑项目碳排数据  ──→  碳排因子库(148国)   ──→  碳核算SaaS      ──→  建筑企业(业主/施工方)
企业能耗数据      ──→  AI碳核算引擎        ──→  碳资产管理      ──→  碳交易市场
供应链数据        ──→  绿色建材库          ──→  绿色供应链管理  ──→  金融机构(绿色信贷)
ESG报告数据       ──→  Scope 3穿透        ──→  ESG合规报告     ──→  监管机构
```

**利润分配**（100元收入拆解）

| 环节 | 毛利率 | 说明 |
|:---|:---:|:---|
| 碳数据采集与清洗 | 15-25% | 建筑行业超60%靠人工填报，采集成本刚性 |
| 碳核算算法研发 | 60-70% | 算法团队是核心成本，边际成本极低 |
| 平台化SaaS交付 | 50-60% | SaaS模式边际成本低，定制化拉低毛利 |
| 碳资产运营服务 | 30-40% | 需要专业碳资产团队，人力成本高 |
| 销售与获客 | 20-30% | ToB销售团队重，CAC高 |

**关键控制节点**：**数据资产型 + 技术壁垒型**
- 碳排因子库覆盖148个国家、50万+因子，形成数据壁垒
- AI碳核算精度与核查机构一致性达95%+，形成技术壁垒
- 中建2万+在建项目碳排数据是建筑行业独占资源

**可优化环节**：建筑行业碳数据采集超60%靠人工填报，数据质量是最大瓶颈。碳排因子库的本地化适配（中国建筑行业专用因子）和数据自动采集是主要优化空间。

### M3 预判稳态B

**原子级需求拆解**

| 用户 | 场景 | 解决什么问题 | 愿付多少钱 |
|:---|:---|:---|:---|

**稳态B推演**：

> （EU CBAM + 碳市场扩容）→（使得建筑行业碳核算从"可选"变为"强制"）→（叠加AI碳核算技术成熟）→ **建筑行业碳管理从"人工核算+咨询驱动"转向"AI平台+数据驱动"，头部平台凭借独占数据资产和行业深度形成寡头格局。**

**中建碳科技在稳态B中的位置**：建筑行业垂直碳管理平台 — 拥有2万+在建项目碳排数据、碳排因子库、绿色建材库，结合AI碳核算技术，形成"数据+算法+行业Know-how"三位一体的竞争优势。

### M4 Timing

**周期定位**：**早期探索 → 爆发增长的过渡期**

- 通用碳管理平台（碳阻迹、远景智能）已完成市场教育
- 建筑行业垂直的碳管理SaaS尚处早期，CECS标准预计2026年发布
- 中建碳科技已有原型，但尚未形成规模化产品

**窗口期判断**：窗口已开，还有 **2-3 年**。原因：
- EU CBAM 2026年全面实施，出口企业合规需求将在2026-2027年集中爆发
- 全国碳市场扩容至八大行业，建筑行业即将被纳入强制碳交易
- CECS标准2026年发布，先发者可抢占标准制定话语权

**太早风险**：中 — 建筑行业碳管理标准尚未完全定型，产品可能需要根据标准调整
**太晚风险**：高 — 碳阻迹（1000+客户）、远景智能（方舟平台）已建立先发优势，国家队（国网新能源云）有垄断性资源

### M5 天花板大小

**四方法交叉验证**

| 方法 | 估算 | 说明 |
|:---|:---|:---|
| **直接数据** | 全球碳管理软件43.66亿美元(2025)→391亿美元(2032) | CAGR 14.69%，中国市场约占15-20% |
| **Top-down** | 中国能碳管理软件50亿元(2025)，CAGR 9%-15% | 建筑行业占比约15-20% → 7.5-10亿元 |
| **Bottom-up** | 中建2万+项目 × 假设10%付费 × 年均10万 = 2亿 | 仅中建体系内，保守估算 |
| **类比法** | 碳阻迹1000+客户 × 年均10万 = 1亿 | 建筑行业垂直至少同等体量 |

**结论**：建筑行业能碳管理可触达市场 **10-30亿元**，支撑十亿级体量公司。若叠加碳资产运营和绿色金融服务，天花板更高。

### M6 集中度

**现状**：**有头部玩家但未形成建筑行业垄断**
- 国家队：国网新能源云、中电联平台 — 电力行业垄断性优势
- 垂直龙头：远景智能（方舟）、阳光慧碳、华为零碳园区 — 能碳一体化
- 创新型SaaS：碳阻迹（1000+客户）、碳衡科技、擎工互联
- 建筑行业垂直：尚无全国性寡头

**趋势**：**C型（分散→集中）★ 最佳时机**
- 碳排因子库和行业数据具有规模效应 — 数据越多，模型越准
- 政策推动（EU CBAM + 碳市场扩容）将加速行业整合
- 2-3年内将出现建筑行业碳管理的头部平台

**匹配策略**：差异化深耕 — 利用中建2万+项目碳排数据和建筑行业Know-how，在建筑行业做深做透，而非与碳阻迹/远景智能在通用市场正面竞争。

**行业预判结论**：🟡 5 模块通过，1 模块需补充（M6集中度需关注竞争格局演变）。进入五步法项目分析，但需重点关注差异化定位问题。

## 三、五步法逐层分析

### Step 1 需求

**目标用户**：建筑央企及大型建筑企业的ESG/碳管理部门、出口型建筑企业、绿色建材供应商

**场景与痛点**：

| 场景 | 痛点 | 刚性 |
|:---|:---|:---:|
| 新建项目碳排放核算 | 人工核算效率低（一个项目需2-3周）、误差大，无法满足绿色建筑认证要求 | 🔴刚性 |
| 施工过程碳排放监控 | 无法实时掌握施工阶段碳排放，难以优化施工方案降低碳排放 | 🟡中等 |
| EU CBAM碳关税申报 | 缺乏符合欧盟标准的碳核算能力，面临高额关税风险 | 🔴刚性 |
| 碳资产管理和交易 | 碳配额管理混乱、碳交易时机把握不准，造成经济损失 | 🟡中等 |
| 绿色供应链管理 | 无法追溯供应链碳排放，Scope 3核算困难 | 🟡中等 |

**替代方案**：碳阻迹/远景智能（通用碳管理平台，缺乏建筑行业深度）、人工咨询（效率低、成本高、难以规模化）

**需求评估三角形**：
- 刚性：🔴 雪中送炭 — EU CBAM合规刚需 + 碳市场扩容强制
- 频次：🟡 中频 — 新建项目核算（项目制）、施工监控（持续）、碳关税申报（年度）
- 普遍性：🔴 广泛 — 所有建筑央企、出口型建筑企业、绿色建材供应商都有需求

**关键假设**：
- H1（P0）：建筑企业愿意为"建筑行业专属"的碳管理SaaS付费（而非直接用碳阻迹/远景智能通用平台）
- H2（P1）：中建2万+项目碳排数据对外部客户（非中建体系内）有足够吸引力

### Step 2 解决方案

**差异化定位**：

> 碳阻迹/远景智能是"通用碳管理平台"，我们是"建筑行业全生命周期能碳管理平台" — 区别在于：我们有**2万+在建项目碳排数据 + 建筑行业碳排因子库 + 绿色建材库**，能回答"建筑项目从设计到运维全生命周期的碳排放是多少、如何优化"，而通用平台只能回答"企业整体碳排放是多少"。

**核心卖点**：一句话 — **"通用平台算企业碳，我们算建筑碳。"**

**产品内核（做了什么、不做什么）**：

| 做 ✅ | 不做 ❌ |
|:---|:---|
| 建筑项目全生命周期碳核算（设计→施工→运维） | 通用企业碳核算（与碳阻迹正面竞争） |
| AI自动提取碳排放数据（七步审核流） | 碳交易经纪业务（不做交易撮合） |
| 绿色建材碳足迹认证 | 碳金融产品设计（不做碳期货/碳基金） |
| EU CBAM碳关税申报辅助 | 国际碳信用开发（不做CDM/VCS项目） |
| 建筑行业碳排因子库维护 | 电力行业碳管理（与国网正面竞争） |

**最小可用版本（MVP）**：
1. 基于中建2万+项目数据，训练建筑碳排放预测模型
2. 整合碳排因子库+绿色建材库
3. 输出建筑项目碳核算报告（AI自动提取+人工复核）
4. 嵌入中建体系内项目做内部验证

**关键假设**：
- H3（P0）：中建碳排数据 + 建筑行业碳排因子库融合后的碳核算模型，精度显著优于通用平台
- H4（P1）：七步审核流+AI自动提取方案能将碳数据采集效率提升50%以上

## 七、备选路径

**Plan A（首选）**：建筑行业全生命周期能碳管理SaaS
- 路径：中建体系内验证 → 央企横向复制 → CBAM客户获取 → 碳资产运营
- 目标：第3年收入5200万，第5年收入2亿+

**Plan B（备选）**：EU CBAM碳关税申报服务（轻量化切入）
- 路径：聚焦出口型建筑企业的CBAM合规需求，提供碳核算+申报服务
- 优势：需求刚性强、客单价高（30万/年）、无需大规模平台建设
- 目标：第3年50家客户，收入1500万/年

**Plan C（退出条件）**：
- 验证期内（6个月）中建体系内≥3个工程局拒绝使用 → 内部需求不成立
- 法律合规审查结论为数据不可对外输出 → 仅限体系内使用，市场天花板大幅缩小
- 碳管理标准变化导致建筑行业碳核算需求弱于预期 → 需求不成立

## 九、与IS-B06能源综合管理的协同关系

能碳平台（IS-B05）与IS-B06中的能源综合管理业务是**天然的上下游关系**：

```
IS-B05 能碳平台（数据+算法层）
  │
  ├── 碳排放核算 → 能源消耗数据输入
  ├── 碳排因子库 → 能源效率基准
  └── AI优化建议 → 节能降碳方案
  │
  ▼
IS-B06 能源综合管理（应用层）
  │
  ├── 建筑能AI优化 → 实际节能效果
  ├── 光储直柔调度 → 绿电消纳
  └── 碳资产运营 → 碳交易变现
```

**建议**：IS-B05 和 IS-B06 能源综合管理应作为"组合拳"推进 — IS-B05 建立碳数据壁垒和技术底座，IS-B06 实现能源优化和碳资产变现。两者共享同一套数据资产和AI能力，边际成本极低。

## 十、核心风险提示

**主要风险**：
1. **数据质量风险**：建筑行业碳数据采集超60%靠人工填报，数据质量是最大瓶颈
2. **竞争格局风险**：碳阻迹（1000+客户）、远景智能（方舟平台）已建立先发优势
3. **标准变化风险**：建筑行业碳管理标准尚未完全定型，产品可能需要根据标准调整
4. **人才风险**：碳咨询+CBAM申报专业人才稀缺，团队能力建设是关键

**应对策略**：
1. 聚焦中建体系内验证，用真实数据打磨模型精度
2. 差异化定位为"建筑行业垂直"，避免与通用平台正面竞争
3. 积极参与CECS标准制定，抢占标准话语权
4. 与碳咨询公司合作，快速补充专业能力
