# AI 工具选型指南

> 面对眼花缭乱的 AI 工具，如何选出最适合自己的？
> 本指南按**使用场景**和**岗位类型**提供选型建议。

---

## 一、按场景选型

### 场景 1：日常对话与问答

| 工具 | 推荐指数 | 理由 |
|------|---------|------|
| **DeepSeek** | ⭐⭐⭐⭐⭐ | 国内直用，免费，中文优秀，推理能力强 |
| **Kimi** | ⭐⭐⭐⭐⭐ | 国内直用，超长文本，联网搜索 |
| **ChatGPT** | ⭐⭐⭐⭐ | 功能最强，但需翻墙 |
| **Claude** | ⭐⭐⭐⭐ | 安全对齐最好，但需翻墙 |

**建议**：日常使用选 **DeepSeek** 或 **Kimi**，两者互补。

```
约束：去除口语化表达，语言正式简洁

[粘贴内容]
```

## 三、快速决策树

```
你有特殊网络环境（翻墙）吗？
├── 有 → 优先考虑 ChatGPT / Claude
└── 没有 → 优先考虑 DeepSeek / Kimi

你的主要工作是？
├── 写文字（公文/报告/文案）
│   ├── 要严谨正式 → Claude
│   └── 要效率优先 → DeepSeek / Kimi
├── 读文档（合同/论文/报告）
│   └── 文档很长 → Kimi（200万字上下文）
├── 数据分析
│   └── ChatGPT / DeepSeek
├── 编程
│   └── Claude Code / Cursor
└── 知识管理
    └── Obsidian + Claude Code

你的预算是？
├── 零预算 → DeepSeek（免费）+ Kimi（免费）
├── 轻度付费 → ChatGPT Plus / Claude Pro
└── 团队预算 → Team 版 + API
```

## 五、避坑指南

| 坑 | 怎么避 |
|---|--------|
| 工具太多，学不过来 | 先精通 2-3 个，不要贪多 |
| 付费后才发现不好用 | 先用免费版充分试用 |
| AI 输出直接复制使用 | 关键信息必须人工核实 |
| 敏感数据上传到公开 AI | 使用企业版或本地部署 |
| 提示词写不好，效果差 | 学习 RTFC 框架，多练习 |
| 收藏了不学，学了不用 | 选一个工作场景，马上实践 |
