# AI 学习路径（零基础版）

> 本学习路径专为**中建发展总部非技术岗位员工**设计，目标是：
> 1. 理解 AI 是什么、能做什么
> 2. 熟练使用主流 AI 工具提升办公效率
> 3. 掌握 Claude Code + Obsidian 构建个人知识库

---

## 第一阶段：认知破冰（1-2 周）

**目标**：消除对 AI 的恐惧和误解，建立正确认知。

### 学习内容

| 主题 | 内容 | 时间 |
|------|------|------|
| [[wiki/concepts/人工智能\|什么是 AI]] | AI 的定义、三大层级、核心分支 | 1小时 |
| [[wiki/concepts/大语言模型\|什么是大语言模型]] | LLM 的工作原理、Token、上下文 | 1小时 |
| AI 能做什么/不能做什么 | 破除常见误区 | 30分钟 |
| 体验 3 个 AI 工具 | ChatGPT / DeepSeek / Kimi 各聊10分钟 | 1小时 |

### 验收标准
- [ ] 能向同事解释清楚"AI 并不理解语言，只是猜下一个词"
- [ ] 能说出 3 个 AI 擅长的事和 3 个不擅长的事
- [ ] 至少注册并使用过 1 个国产 AI 工具

### 推荐资源
- 本知识库 [[wiki/concepts/人工智能\|人工智能概念页]]
- 本知识库 [[wiki/concepts/大语言模型\|大语言模型概念页]]
- 视频：B站搜索"10分钟搞懂AI大模型"（选播放量高的）

## 第二阶段：提示工程入门（2-3 周）

**目标**：学会"跟 AI 说话"，让 AI 输出真正有用的结果。

### 学习内容

| 主题 | 内容 | 时间 |
|------|------|------|
| [[wiki/concepts/提示工程\|提示工程基础]] | RTFC 框架、角色扮演、上下文 | 2小时 |
| 六大核心技巧 | 角色法、上下文、示例引导、思维链、格式指定、分步拆解 | 3小时 |
| 场景实战 | 写邮件、会议纪要、数据分析、报告撰写 | 5小时 |

### 实战练习

每天至少用一个 AI 工具完成一项工作任务：

| 天数 | 练习任务 |
|------|---------|
| 第1天 | 用 AI 写一封工作邮件 |
| 第2天 | 用 AI 整理一份会议纪要 |
| 第3天 | 用 AI 润色一段工作总结 |
| 第4天 | 用 AI 解释一个专业术语 |
| 第5天 | 用 AI 头脑风暴 10 个方案 |
| 第6天 | 用 AI 分析一组数据 |
| 第7天 | 用 AI 写一份周报 |

### 验收标准
- [ ] 掌握 RTFC 提示框架
- [ ] 能写出"直接可用"的 AI 辅助产出（不需要大改）
- [ ] 积累 10 个自己常用的提示词模板

| 你的需求 | 推荐工具 |

## 第四阶段：知识库构建（3-4 周）

**目标**：用 Obsidian + Claude Code 建立个人知识库。

### 学习内容

| 主题 | 内容 | 时间 |
|------|------|------|
| [[wiki/concepts/知识库与RAG\|知识库与 RAG]] | 概念、工作流程、价值 | 1小时 |
| Obsidian 基础 | 安装、界面、双向链接、图谱 | 2小时 |
| Markdown 语法 | 标题、列表、链接、表格 | 1小时 |
| 目录结构设计 | 设计适合自己的知识库结构 | 2小时 |
| 模板制作 | 会议纪要、读书笔记、项目复盘模板 | 2小时 |
| Claude Code 集成 | 用 AI 管理知识库 | 3小时 |

### 知识库搭建步骤

```
第1周：搭建骨架
  - 安装 Obsidian
  - 创建 Vault
  - 设计目录结构
  - 创建 3-5 个模板

第2周：迁移内容
  - 把散落在各处的笔记迁移进来
  - 微信收藏的文章整理入库
  - 会议记录归档

第3周：建立连接
  - 在笔记间建立双向链接
  - 创建 MOC（地图页）
  - 用 Claude Code 分析知识网络

第4周：形成习惯
  - 每日/每周固定时间维护
  - 养成"先入库再使用"的习惯
  - 用知识库辅助实际工作输出
```

### 验收标准
- [ ] 知识库包含至少 50 条笔记
- [ ] 笔记间有双向链接，能在图谱视图中看到关联
- [ ] 能用 AI 基于知识库回答"我关于XX主题记了哪些内容"
- [ ] 形成固定的知识管理习惯（至少持续 2 周）

## 给中建发展员工的特别建议

1. **从工作出发**：不要为学而学，先选一个最痛的工作场景，用 AI 解决它
2. **先国产后国际**：DeepSeek、Kimi 零门槛，建议从这里开始
3. **抱团学习**：和同事组成学习小组，每周分享一个 AI 使用技巧
4. **允许试错**：AI 工具迭代很快，今天学的明天可能就过时了，保持开放心态
5. **记住公式**：

```
你的 AI 价值 = 你的专业知识 × AI 工具使用能力
```

AI 不会替代你，但会用 AI 的同事会替代不会用的人。
