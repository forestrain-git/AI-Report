# 国企AI宣讲：政策锚定与考核指标

> 面向国企中高层的AI宣讲素材——政策锚定模块，回答"这不是技术选项，而是关乎行业存亡的战略选择"

---

## 一、核心政策文件梳理

### 1.1 国务院国资委关键政策

| 政策文件 | 发布时间 | 核心内容 |
|:---|:---|:---|
| 《关于加快推进国有企业数字化转型工作的通知》 | 2020年 | 首次系统部署国企数字化转型，要求制定总体规划和路线图 |
| 《关于推动中央企业加快发展战略性新兴产业的指导意见》 | 2023年 | 将AI列为央企战略性新兴产业重要方向 |
| **"AI+"专项行动** | 2024-2025年 | 要求央企将AI技术融入生产经营各环节，建设行业大模型 |
| 国资委"一利五率"考核体系 | 2024年起 | 研发投入强度、战略性新兴产业收入占比等纳入央企负责人经营业绩考核（间接涵盖AI） |
| **《关于加快推进中央企业人工智能发展的指导意见》** | 2025年1月（1.14披露） | 国资委印发，要求央企把发展AI作为**"一把手工程"**，领导人员带头提升AI素养，纳入考核评价 — [21财经](https://www.21jingji.com/article/20250114/herald/54f6d5e8c4e4b7d57f3bb16bb7c50e45.html) |
| **国资委"AI+"专项行动部署** | 2025年3月25日 | 中央企业人工智能部署推进会，张玉卓出席，要求央企加快AI部署 — [国资委官网](https://en.sasac.gov.cn/2025/03/25/c_1185.htm) |
| **AI素养纳入领导干部考核** | 2025年5月8日 | 国资委要求将AI素养纳入领导干部培训体系和考核评价体系 — [央视新闻/澎湃新闻](https://www.thepaper.cn/newsDetail_forward_30406012) |

### 1.2 2025年两会"人工智能+"行动

- 2025年政府工作报告继续**深化"人工智能+"战略**
- 推动人工智能技术与各行各业深度融合
- 加快AI基础设施建设，包括算力中心、大模型等
- 强调AI在制造业、农业、服务业等领域的广泛应用

### 1.3 "新质生产力"战略

- 2024-2025年的**核心经济概念**
- 以科技创新为驱动，推动产业升级和经济结构转型
- 涵盖**人工智能、量子计算、生物技术、新能源**等前沿领域
- 多位代表委员建议将AI应用和新质生产力发展纳入国企考核指标体系

## 二、央企AI考核指标体系

### 2.1 考核纳入经营业绩

> **宣讲要点**：2025年5月8日，国务院国资委明确要求**将AI素养纳入领导干部培训体系和考核评价体系**（来源：[央视新闻/澎湃新闻](https://www.thepaper.cn/newsDetail_forward_30406012)）。部分央企（如中铝集团、中国中煤）已将AI指标融入本企业业绩考核。AI不是"可做可不做"，而是**政策考核方向已明确**。

### 2.2 具体考核维度

| 考核维度 | 具体指标 | 说明 |
|:---|:---|:---|
| **研发投入** | AI相关研发经费投入强度 | 衡量企业对AI的投入力度 |
| **场景落地** | AI技术在核心业务场景的应用数量和覆盖率 | 衡量AI的落地深度 |
| **数字化程度** | 业务流程数字化覆盖率、数据共享率 | 量化数字化转型进展 |
| **人才建设** | AI领域专业人才引进和培养情况 | 人才储备指标 |
| **创新成效** | AI相关专利、标准、成果转化情况 | 创新产出指标 |
| **数据治理** | 数据资产管理和数据治理能力 | 数据基础设施水平 |

### 2.3 差异化考核设计

| 部门类型 | 考核重点 |
|---------|---------|
| 职能部门 | AI技术在业务流程中的应用成效 |
| 生产部门 | 智能系统建设质量、数字化率 |
| 技术部门 | 核心技术突破、自主创新能力 |

## 三、央企数字化转型具体要求

### 3.1 国资委"AI+"专项行动要求

1. 将AI技术融入企业生产经营的各个环节
2. 推动**智能制造、智慧能源、智慧交通**等场景落地
3. 加大AI领域的研发投入
4. 建设**行业大模型**和通用大模型
5. 推进关键核心技术**国产替代**

### 3.2 数字化转型目标

| 时间节点 | 目标要求 |
|:---|:---|
| 2025年 | 央企数字化转型取得显著成效，关键业务数字化率达到较高水平 |
| "十五五"末 | 以中国海油为标杆：力争整体**数字化率达到80%以上** |
| 长期 | 全面建成数字化、智能化企业体系 |

### 3.3 2025年重点工作方向

- 推进央企**"科改行动"**和**"双百行动"**中数字化相关任务
- 深化**工业互联网**在制造业中的应用
- 推动**大模型**在企业中的落地应用
- 加强央企间的数据共享与协同
- 加快**"数字国资委"**建设
- 加强**数据治理**和**网络安全**

### 3.4 探索中的新指标

- 代表建议设立国企**"科技创新专项考核"**
- 将AI研发与应用成果作为企业**负责人任期考核**的重要内容
- 探索建立**"新质生产力发展指数"**，用于衡量国企转型成效

## 五、PPT宣讲话术素材

### 5.1 金句（可用于PPT开篇）

> **"这不是技术选项，而是关乎行业存亡的战略选择。"**
> ——国资委已要求将AI素养纳入领导干部考核评价体系（2025.5.8）

> **"广泛应用AI的企业正在重构行业格局。"**
> ——同行都在行动，先建的被树为典型，后建的只能交作业

> **"新质生产力的核心引擎就是AI。"**
> ——2025两会政府工作报告明确方向

> **"谁的数据治理做得好，谁的AI就能先跑起来。"**
> ——数据是AI的燃料，没有数据就没有AI

### 5.2 当前政策要求（适合PPT一页展示）

**直接列条目，不讲宏大叙事：**

1. **2025两会**：政府工作报告深化"人工智能+"战略，推动AI与各行各业融合
2. **国资委"AI+"专项行动**（2025.3.25）：要求央企加快AI部署，六大重点任务
3. **AI素养纳入考核**（2025.5.8）：国资委要求将AI素养纳入领导干部培训体系和考核评价体系
4. **新《网络安全法》**（2026.1.1生效）：罚款上限1000万，负责人个人责任，AI专项监管
5. **不是做不做的问题，是怎么做的问题**

### 5.3 对比表（制造紧迫感）

| 维度 | 先行央企 | 滞后企业 |
|:---|:---|:---|
| **政策红利** | 被树为典型，获得政策倾斜 | 只能交作业，被动追赶 |
| **人才争夺** | 吸引AI人才，形成技术壁垒 | 人才流失，技术代差扩大 |
| **市场竞争力** | 降本增效，报价更有优势 | 成本居高不下，招投标失利 |
| **行业重构** | AI融入核心业务，抢占新赛道 | 被动追赶，错失窗口期 |
