# 国企AI宣讲：政策锚定与考核指标

> 面向国企中高层的AI宣讲素材——政策锚定模块，回答"这是政治任务，不是技术选项"

---

## 一、核心政策文件梳理

### 1.1 国务院国资委关键政策

| 政策文件 | 发布时间 | 核心内容 |
|:---|:---|:---|
| 《关于加快推进国有企业数字化转型工作的通知》 | 2020年 | 首次系统部署国企数字化转型，要求制定总体规划和路线图 |
| 《关于推动中央企业加快发展战略性新兴产业的指导意见》 | 2023年 | 将AI列为央企战略性新兴产业重要方向 |
| **"AI+"专项行动** | 2024-2025年 | 要求央企将AI技术融入生产经营各环节，建设行业大模型 |
| 国资委数字化转型考核纳入经营业绩考核 | 2024年起 | 数字化转型指标正式纳入央企负责人经营业绩考核 |

### 1.2 2025年两会"人工智能+"行动

- 2025年政府工作报告继续**深化"人工智能+"战略**
- 推动人工智能技术与各行各业深度融合
- 加快AI基础设施建设，包括算力中心、大模型等
- 强调AI在制造业、农业、服务业等领域的广泛应用

### 1.3 "新质生产力"战略

- 2024-2025年的**核心经济概念**
- 以科技创新为驱动，推动产业升级和经济结构转型
- 涵盖**人工智能、量子计算、生物技术、新能源**等前沿领域
- 多位代表委员建议将AI应用和新质生产力发展纳入国企考核指标体系

## 二、央企AI考核指标体系

### 2.1 考核纳入经营业绩

> **宣讲要点**：AI推进力度已**正式纳入央企负责人经营业绩考核**，不是"可做可不做"，而是**做了加分、不做扣分**。

### 2.2 具体考核维度

| 考核维度 | 具体指标 | 说明 |
|:---|:---|:---|
| **研发投入** | AI相关研发经费投入强度 | 衡量企业对AI的投入力度 |
| **场景落地** | AI技术在核心业务场景的应用数量和覆盖率 | 衡量AI的落地深度 |
| **数字化程度** | 业务流程数字化覆盖率、数据共享率 | 量化数字化转型进展 |
| **人才建设** | AI领域专业人才引进和培养情况 | 人才储备指标 |
| **创新成效** | AI相关专利、标准、成果转化情况 | 创新产出指标 |
| **数据治理** | 数据资产管理和数据治理能力 | 数据基础设施水平 |

### 2.3 差异化考核设计

| 部门类型 | 考核重点 |
|---------|---------|
| 职能部门 | AI技术在业务流程中的应用成效 |
| 生产部门 | 智能系统建设质量、数字化率 |
| 技术部门 | 核心技术突破、自主创新能力 |

## 三、央企数字化转型具体要求

### 3.1 国资委"AI+"专项行动要求

1. 将AI技术融入企业生产经营的各个环节
2. 推动**智能制造、智慧能源、智慧交通**等场景落地
3. 加大AI领域的研发投入
4. 建设**行业大模型**和通用大模型
5. 推进关键核心技术**国产替代**

### 3.2 数字化转型目标

| 时间节点 | 目标要求 |
|:---|:---|
| 2025年 | 央企数字化转型取得显著成效，关键业务数字化率达到较高水平 |
| "十五五"末 | 以中国海油为标杆：力争整体**数字化率达到80%以上** |
| 长期 | 全面建成数字化、智能化企业体系 |

### 3.3 2025年重点工作方向

- 推进央企**"科改行动"**和**"双百行动"**中数字化相关任务
- 深化**工业互联网**在制造业中的应用
- 推动**大模型**在企业中的落地应用
- 加强央企间的数据共享与协同
- 加快**"数字国资委"**建设
- 加强**数据治理**和**网络安全**

### 3.4 探索中的新指标

- 代表建议设立国企**"科技创新专项考核"**
- 将AI研发与应用成果作为企业**负责人任期考核**的重要内容
- 探索建立**"新质生产力发展指数"**，用于衡量国企转型成效

## 五、PPT宣讲话术素材

### 5.1 金句（可用于PPT开篇）

> **"这不是技术选项，这是政治任务。"**
> ——AI推进力度已纳入央企负责人经营业绩考核

> **"不做AI的国企正在被重构。"**
> ——同行都在行动，先建的被树为典型，后建的只能交作业

> **"新质生产力的核心引擎就是AI。"**
> ——2025两会政府工作报告明确方向

> **"谁的数据治理做得好，谁的AI就能先跑起来。"**
> ——数据是AI的燃料，没有数据就没有AI

### 5.2 政策逻辑链（适合PPT一页展示）

```
国家意志
  └── 2025两会：深化"人工智能+"行动
      └── 新质生产力：科技创新驱动产业升级
          └── 国资委：AI+专项行动 + 数字化转型考核
              └── 央企负责人：经营业绩考核纳入AI指标
                  └── 你（国企中高层）：不是做不做，是怎么做的问题
```

### 5.3 对比表（制造紧迫感）

| 维度 | 先行央企 | 滞后企业 |
|:---|:---|:---|
| **政策红利** | 被树为典型，获得政策倾斜 | 只能交作业，被动追赶 |
| **人才争夺** | 吸引AI人才，形成技术壁垒 | 人才流失，技术代差扩大 |
| **市场竞争力** | 降本增效，报价更有优势 | 成本居高不下，招投标失利 |
| **政绩考核** | 数字化指标加分 | 考核扣分，领导责任 |
