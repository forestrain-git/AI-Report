## 企业背景
英伟达（NVIDIA）是全球最大的 GPU 和 AI 计算公司，近年来从游戏/数据中心向工业元宇宙扩展，Omniverse 是其面向 AEC 行业的数字孪生平台。

## AI产品：NVIDIA Omniverse

### 时间线
- **2020**：Omniverse 公测发布
- **2022-2023**：扩展 AEC 行业应用，基于 OpenUSD
- **2024-2025**：与 Autodesk/Bentley/Trimble 全线合作；Omniverse Cloud API 发布

### 技术细节
- **核心定位**：开放的云原生多GPU平台，用于虚拟协作和实时物理级仿真
- **底层标准**：基于 Pixar 的通用场景描述（OpenUSD）框架，NVIDIA 主导 AOUSD 联盟
- **实时协作**：多个团队成员在 Revit/SketchUp/Rhino 等不同软件中同时对同一项目协作
- **AEC 案例**：Zaha Hadid Architects 使用 Omniverse + OpenUSD 进行设计迭代，迭代周期提升3倍

### 合作生态
| 合作方 | 合作内容 |
|--------|---------|
| **Autodesk** | Revit/3ds Max/Maya 的 Omniverse Connector |
| **Bentley** | LumenRT for Omniverse，iTwin 集成 |
| **Trimble** | SketchUp Connector，Omniverse Cloud API 集成 |
| **西门子** | Xcelerator × Omniverse Cloud API |

## 对中建发展的参考意义
英伟达是典型的"从旁边杀进来"的跨界者——它的核心不是建筑软件，而是 GPU 和 AI，但它通过 Omniverse 连接了 Autodesk/Bentley/Trimble 三大生态。这说明在 AI 时代，行业边界正在模糊。中建发展的策略不应该局限于传统建筑业视角，而要看到"AI公司+传统建筑软件公司+云厂商"三者正在重新画行业地图。
