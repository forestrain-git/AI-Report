## 企业背景
西门子（Siemens）是全球最大的工业自动化公司之一，智能基础设施部门是其核心业务之一。Building X 是西门子 Xcelerator 生态系统的建筑管理 SaaS 平台。

## AI产品：Building X

### 时间线
- **2022.6**：Building X 正式发布
- **2024-2025**：持续集成AI能力，包括 Ask Building X（生成式AI助手）、Comfort AI等
- **2026.1**：与 BizzTech 合作引入 agentic AI

### 技术细节
- **Ask Building X**：基于生成式AI的自然语言产品文档查询（2026.1发布）
- **Comfort AI**：利用历史和 occupancy 数据优化 HVAC 设定点
- **Lifecycle Twin**：建筑全生命周期数字孪生（"单一事实源"）
- **360 Viewer**：基于 NavVis IVION 的空间数字孪生

### 量化效果
| 指标 | 数值 |
|------|------|
| Comfort AI 月能耗节省 | **最高6.5%** |
| 客户报告整体节能 | **最高30%** |
| 西班牙医院项目节能 | **35%**（实测） |

### 与英伟达 Omniverse 合作
- 2024.3（GTC）：西门子将 NVIDIA Omniverse Cloud API 集成到 Xcelerator
- 2025.10（GTC 华盛顿）：展示 AI 时代工业技术栈
- 2026.1（CES）：联合推出"工业 AI 操作系统"

## 对中建发展的参考意义
西门子是工业自动化的老牌玩家，Building X 代表其试图用工业数字化经验改造建筑运营。与英伟达 Omniverse 的合作说明"工业×IT"正在成为趋势。中建发展在建筑运营领域有场景优势（水务、环保），可以考虑类似"传感器+AI+数字孪生"的路径。
