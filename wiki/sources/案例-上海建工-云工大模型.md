## 企业背景
上海建工集团是中国最大的地方建筑企业之一，业务覆盖设计、施工、运维全产业链，承接了上海中心大厦、上海大歌剧院等标志性项目。

## AI项目：云工大模型（CloudWorker LLM）

### 时间线
- **2024**：正式发布国内首个建筑AI MaaS系统
- **2025**：首家通过国家级AI算法备案的建筑施工企业；入选工信部"AI赋能新型工业化典型案例"（唯一建筑运维案例）

### 技术细节
- **架构**：MoE多模态混合专家模型
- **六大子系统**：
  | 子系统 | 功能 |
  |--------|------|
  | 云工·答（Construction-GPT） | 建筑知识问答 |
  | 云工·算 | AI算量 |
  | 云工·图 | AI识图/出图 |
  | 云工·案 | 施工方案 |
  | 云工·测 | 智能检测 |
  | 云工·查 | 安全巡查 |
- **应用场景**：东方枢纽上海东站、上海大歌剧院等百余项重大工程
- **BIM+AI**：在上海大歌剧院实现近300张深化图纸自动生成

### 量化效果
| 指标 | 数值 |
|------|------|
| 行业用户 | **10万名** |
| 累计使用 | **超2500万人次** |
| 能耗减少 | **5%-10%**（智慧运维平台） |
| 故障诊断时间 | **缩短50%** |
| 环境满意度 | **提升18%** |

## 对中建发展的参考意义
上海建工是和中建发展最接近的对标——同为建工企业，都面向建筑全产业链。其"云工大模型"选择了 MaaS（模型即服务）模式，不是自研基础大模型，而是在成熟模型上做行业适配。这是一个务实的路径。中建发展的"建证大模型平台"已经在上线，云工大模型的运营数据（10万用户/2500万次使用）可以作为参考基准。
