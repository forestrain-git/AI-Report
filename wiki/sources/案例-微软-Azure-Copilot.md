## 企业背景
微软是全球最大的操作系统和云服务公司之一，通过 Azure 云、AI（Copilot）、混合现实（HoloLens）三条线渗透建筑行业。

## AI产品矩阵

### 1. Azure Digital Twins（数字孪生IoT平台）
- **时间**：2020年发布，2022-2025持续增强
- **定位**：PaaS 平台，用于创建物理环境的数字副本
- **核心能力**：DTDL 开放建模 + IoT Hub 实时数据 + 3D Scenes Studio + Azure Machine Learning 预测分析
- **被 Bentley iTwin 全线集成**：Bentley 的 iTwin 平台构建于 Azure 之上

### 2. Microsoft 365 Copilot
- **时间**：2023年发布，2024-2025年建筑行业大规模部署
- **采用案例**：Balfour Beatty（720万镑投资）、Kier（10,000员工）、Ferrovial（15国家全员部署）
- **建筑行业效果**：生产率↑14-15%，每人每周节省90分钟

### 3. HoloLens 2（混合现实）
- **时间**：2019年发布，2024年10月停产，2025年2月微软退出硬件业务
- **建筑应用**：BIM 模型1:1叠加到物理施工环境（NEXT-BIM、Trimble Connect 等）
- **⚠️ 现状**：技术已验证但硬件已停产，支持下限于2027.12

## 对中建发展的参考意义
微软在建筑业的布局是全栈的：云（Azure）+ AI（Copilot）+ 数字孪生（DT）+ AR（HoloLens）。其中 Copilot 在 Balfour Beatty 的部署证明 LLM 对建筑业办公效率的提升是立竿见影的。中建发展可以考虑从"建筑行业 Copilot"（对标云工大模型或 StoaOne）切入，用 LLM 解决建筑文档处理的痛点。
