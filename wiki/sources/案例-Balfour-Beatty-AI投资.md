## 企业背景
Balfour Beatty 是英国最大的基础设施集团之一，总部伦敦，业务覆盖公路、铁路、医院、学校等公共基础设施的建设和维护。

## AI项目：StoaOne + Microsoft Copilot

### 时间线
- **2023-2024**：自研 LLM 助手 **StoaOne**（基于 Microsoft Azure），覆盖安全、采购、项目知识管理等
- **2025.7**：宣布 **720万英镑 AI 投资**，与微软签署四年合作至2029年，全员部署 Microsoft 365 Copilot
- **2025.9**：在美国举办首次 AI Hackathon（70名员工参与）

### 技术细节
- **StoaOne**：专有 LLM 生成式 AI 助手，从公司安全云中挖掘数十亿数据点，提供即时洞察（历史项目、采购、规划和执行）
- **Copilot 部署**：覆盖 Outlook、Excel、Word、Teams 等全模块，面向办公室和工地岗位
- **AI 智能代理**：在 A9 Dualling 项目（1.85亿英镑）试点 AI 驱动的质量/健康/安全/保证（QHSA）流程

### 量化效果
| 指标 | 数值 |
|------|------|
| AI总投资 | **720万英镑**（英国建筑业最大单笔AI投资） |
| 生产率提升 | **14-15%** |
| 员工认为 Copilot 改善工作 | **75%** |
| 认为日常事务精神消耗减少 | **77%** |
| 认为有助于沟通 | **78%** |

## 对中建发展的参考意义
Balfour Beatty 和中建发展的体量、业务复杂度有可比性。其"自研 LLM + 全员 Copilot"的双层策略值得参考：自研的 StoaOne 解决行业专属知识问答，通用 Copilot 解决日常办公效率。
