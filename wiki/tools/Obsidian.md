# Obsidian

## 工具简介

Obsidian 是一款**本地优先的笔记和知识管理软件**，以 Markdown 格式存储所有内容。它是构建"第二大脑"和"个人知识库"的最热门工具之一。

### 一句话定位

Obsidian 是你的**私人数字图书馆**——所有笔记都保存在你自己的电脑上，不依赖云端，永不会被服务商关闭或审查。

## 核心特点

### 1. 本地存储，数据完全私有

```
❌ 其他笔记软件：数据存在厂商服务器，可能倒闭、收费、审查
✅ Obsidian：所有笔记是本地 .md 文件，你用任何文本编辑器都能打开
```

### 2. 双向链接（Wiki Links）

```markdown
在笔记 A 中写：
"最近在学习 [[人工智能]] 的相关内容..."

Obsidian 会自动：
- 在"人工智能"笔记下方显示"有哪些笔记链接到这里"
- 生成可视化的知识图谱，展示笔记间的关联
```

### 3. 强大的插件生态

Obsidian 有数千个社区插件，几乎可以无限扩展功能：

| 插件类型 | 代表插件 | 功能 |
|---------|---------|------|
| 日历 | Calendar | 每日笔记管理 |
| 看板 | Kanban | 项目管理 |
| 数据库 | Dataview | 像查数据库一样查笔记 |
| 模板 | Templater | 自动化生成笔记模板 |
| AI 助手 | BMO Chatbot / Smart Connections | 集成 AI |
| 思维导图 | Mind Map | 笔记可视化 |
| Excalidraw | Excalidraw | 手绘风格图表 |

### 4. Markdown 纯文本

```markdown
# 这是一级标题
## 这是二级标题
- 列表项
- **粗体** *斜体*
[[双向链接]]
[外部链接](https://example.com)
```

- 格式简单，永远不会"打不开"
- 任何 AI 都能直接读取和处理
- 方便版本控制（Git）

## 基础使用

### 创建知识库（Vault）

1. 下载 Obsidian：https://obsidian.md
2. 创建新 Vault（选择一个本地文件夹）
3. 开始写笔记

### 核心操作

| 操作 | 方法 |
|------|------|
| 新建笔记 | `Ctrl+N` 或点击"新笔记" |
| 双向链接 | 输入 `[[笔记名]]` |
| 查看图谱 | 点击左侧"图谱视图" |
| 分屏 | `Ctrl+点击` 笔记链接 |
| 搜索 | `Ctrl+Shift+F` 全局搜索 |
| 命令面板 | `Ctrl+P` 调出所有命令 |

### 推荐目录结构

```
My-Vault/
├── 00-Inbox/              # 收集箱
├── 01-Daily/              # 每日笔记
├── 02-Notes/              # 主体笔记
│   ├── concepts/          # 概念卡片
│   ├── projects/          # 项目笔记
│   └── people/            # 人物笔记
├── 03-MOC/                # 地图页
├── 04-Outputs/            # 输出物
├── 05-Templates/          # 模板
└── 06-Archive/            # 归档
```

## 推荐插件安装

### 必装插件（官方插件，无需安装）
- **标签面板**：管理标签
- **反向链接**：查看哪些笔记链接到当前笔记
- **图谱视图**：可视化知识网络
- **模板**：快速插入模板

### 推荐社区插件

1. **Templater** — 高级模板
   - 自动插入日期、变量、动态内容

2. **Dataview** — 笔记数据库
   - 用类 SQL 语法查询笔记
   - 自动生成列表、表格

3. **Calendar** — 日历视图
   - 配合每日笔记使用

4. **Kanban** — 看板
   - 项目管理、待办事项

5. **Smart Connections** — AI 语义搜索
   - 自动找到与当前笔记"相关"的其他笔记
   - 本地运行，不依赖云端 API

## Obsidian + Claude Code 工作流

这是 2025-2026 年最热门的知识管理方案：

```
┌─────────────────────────────────────────────────────────────┐
│                     日常工作流                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 收集      随手记、复制文章 → 丢进 00-Inbox/              │
│       ↓                                                     │
│  2. 整理      用 Claude Code 帮助分类、打标签、写摘要        │
│       ↓                                                     │
│  3. 连接      在 Obsidian 中建立双向链接 [[ ]]               │
│       ↓                                                     │
│  4. 输出      基于知识库写报告、做 PPT                      │
│       ↓                                                     │
│  5. 维护      定期用 Claude Code 检查链接、更新过期内容      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 具体场景

**场景 1：会议纪要自动化**
```
会议中：手写或语音记录要点
会议后：把要点粘贴到 Obsidian
        → 用 Claude Code "请整理成标准会议纪要格式"
        → 保存到 02-Notes/meetings/2026-04-27-项目复盘.md
        → 添加标签 #项目管理 #XX项目
```

**场景 2：读书笔记沉淀**
```
读完一本书：
1. 在 Obsidian 创建笔记（用模板）
2. 记录核心观点、金句、自己的思考
3. 链接到相关的已有笔记
4. 让 Claude Code 帮忙"找出这本书观点和我之前笔记的冲突之处"
```

**场景 3：项目复盘**
```
项目结束后：
1. 收集项目过程中的所有文档
2. 用 Claude Code 分析，提取经验教训
3. 生成复盘报告，存入知识库
4. 链接到相关项目，形成经验积累
```

## 局限性与注意事项

- **移动端体验**：手机端编辑不如电脑端方便
- **学习曲线**：双向链接、插件等概念需要时间适应
- **图片附件**：需要管理附件文件夹
- **协作困难**：本地文件不方便多人实时协作
