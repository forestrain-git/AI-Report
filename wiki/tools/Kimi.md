# Kimi

## 工具简介

Kimi 是由中国公司**月之暗面（Moonshot AI）**开发的 AI 对话助手，以**超长上下文处理能力**和**对中文的深度优化**著称。

### 一句话定位

Kimi 是**最擅长"读长文"的国产 AI**——你可以扔给它一本 300 页的书、一份 100 页的合同，它都能快速总结要点。

## 核心特点

### 1. 超长上下文

| 版本 | 上下文长度 | 能处理什么 |
|------|-----------|-----------|
| Kimi 标准版 | 200K Token | 几十页文档 |
| **Kimi 长文本版** | **256K（约25-50万字）** | **整本书、多份合同、系列报告** |

这是 Kimi 最大的差异化优势。

### 2. 联网搜索

Kimi 内置联网搜索，可以：
- 回答最新事件（训练数据之外的）
- 搜索网页并总结
- 引用来源（部分场景）

### 3. 文件解析

支持直接上传并分析：
- PDF、Word、Excel、PPT
- 图片（OCR 识别）
- 多个文件同时分析

### 4. 中文优化

- 中文表达自然流畅
- 理解中文语境和文化背景
- 支持中文古籍、诗词等

## 使用场景

### 场景 1：读长文档

```
上传：一份 80 页的项目可行性研究报告
提问："这份报告的核心结论是什么？风险点有哪些？"
→ Kimi 快速总结关键信息
```

### 场景 2：多文档对比

```
上传：3 份不同供应商的报价单
提问："对比这3份报价，各有什么优劣？"
→ Kimi 横向对比分析
```

### 场景 3：合同审查

```
上传：一份合作协议
提问："这份合同有哪些对甲方不利的条款？"
→ Kimi 逐条分析（⚠️ 仅供参考，重要合同仍需专业法务审核）
```

### 场景 4：网页内容总结

```
粘贴网页链接或内容
提问："总结这篇文章的核心观点"
→ Kimi 提炼要点
```

## 使用方式

### 网页版
- 访问：kimi.moonshot.cn
- 国内直接访问，无需翻墙
- 支持微信扫码登录

### 手机 APP
- iOS / Android 应用商店搜索"Kimi"
- 支持语音输入

### API
- 开发者可通过 Moonshot API 接入
- 支持长文本、文件解析等功能

## 局限性与注意事项

- **复杂推理**：在数学、逻辑推理上略逊于 GPT-4 和 Claude
- **创意写作**：文学创作、诗歌等情感表达上还有提升空间
- **幻觉问题**：和所有 LLM 一样，可能编造信息，需核实
- **专业判断**：法律、医疗等专业领域仅供参考
