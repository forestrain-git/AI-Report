## 核心决策

### 叙事驱动：从"压力驱动"切换到"时机驱动"

- **旧逻辑**：政策要求 → 行业落后 → 同行在跑 → 必须动（恐惧驱动）
- **新逻辑**：时代到了 → 技术成熟 → 行业有空间 → 我们看见了 → 主动选择动（清醒驱动）
- 政策信号重新定位为"趋势印证"，而非"上级命令"
- "干AI不是上级逼的，是技术市场时代到了，我们主动选择要搞——这是商业和市场选择"

### 整体结构：从六段并列改为三幕递进

```
旧结构（六段式，信息并列）:
政策 → 对标 → 战略 → 技术 → 组织 → 行动

新结构（三幕式，叙事递进）:
第一幕：时机已到（5页）→ 第二幕：我们怎么选（5页）→ 第三幕：从今天开始（5页）
总页数：~15页正文 + 附录
```

## 关键设计原则

### 1. 调性：中正平和，贯穿全稿
- 不评价集团做得好不好
- 不吹不黑
- 只说政策事实 + 中建发展该怎么选择
- 不引用领导的自我批评（文兵四短板）
- 不把集成包装成自研（建证大模型）

### 2. 表达方式对照
- "四面楚歌" → "行业正在发生积极变化"
- "不行动不行了" → "行动的时机已经成熟"
- "再不追就晚了" → "窗口期明确，现在是投入的最好时点"
- "我们全部避开了" → "这些风险我们在方法论层面已做了规避设计"

### 3. 常识性红线
- 听众是中建发展全体人员（领导到员工），中建发展总部是核心
- "中建电商是中建发展的子公司"等常识性表述绝对不能出现
- 所有素材和论述必须核实，明显错误的内容不能讲

### 4. PPT与逐字稿的分工
- **PPT不能写但现场可以说的**：文兵四短板呼应、文兵"做应用不做大模型"的明确引用、建证大模型真实评价
- **逐字稿单独成文件**，PPT大纲确定后再出

### 5. 两个推进方向定位
- 不是决策结论，是"抛砖引玉"的例子
- 最终方向待下个月AI研讨会讨论确定
- 每张例卡需加"供参考"标识

### 6. AI安全帽的AI关联论证
- 端侧AI：跌倒检测算法、电子围栏、SOS联动
- 云端AI：安全行为评分模型
- 数据变现：保险精算数据接口
- 一句话："59块的帽子是获客成本，保险公司的年费才是利润。"

### 7. 四层筛选参考来源
- deploy/方法论.html：行业预判×五步法×七维评分×20张硬伤卡牌
- deploy/index.html：57个方向完整筛选结果
- wiki/concepts/四层筛选框架.md：框架定稿
